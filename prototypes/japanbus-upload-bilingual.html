GTFSフィードをアップロードGTFS feed’ini yükle

同じfeedを既存のJapanBus FeedValidatorとGTFS Analyzerで確認し、結果を一つの画面で比較するための入口です。Aynı feed’i mevcut JapanBus FeedValidator ve GTFS Analyzer ile kontrol edip sonuçları tek ekranda görmek için başlangıç noktasıdır.

!
現在は画面フローのプロトタイプです。Bu ekran şu anda akış prototipidir. 下の送信ではfeedの実測はまだ行わず、選択情報を結果画面へ渡します。結果画面のスコアと指摘はKuwanaサンプルであり、アップロードしたfeedの判定ではありません。 Gönder düğmesi şu aşamada feed’i gerçekten çalıştırmaz; yalnızca seçimi sonuç ekranına taşır. Sonuç ekranındaki skor ve bulgular Kuwana örneğidir, yüklediğiniz feed’in kararı değildir.

検証対象を選択Doğrulanacak feed’i seç

ZIPファイルまたは公開されているfeed URLを指定します。ZIP dosyası veya erişilebilir bir feed URL’si seçin.

ステップ 1 / 3Adım 1 / 3

URLは http / https で始まる必要があります。ブラウザ制限により取得できない場合はZIPを選択してください。URL http / https ile başlamalıdır. Tarayıcı kısıtı nedeniyle alınamazsa ZIP dosyasını seçin.

GTFS-JPプロファイルGTFS-JP profili

Auto / V3 / V4は検証範囲の選択です。feedの公式GTFS-JP版を自動判定する機能ではありません。Auto / V3 / V4 doğrulama kapsamını seçer. Feed’in resmî GTFS-JP sürümünü otomatik tespit etmez.
