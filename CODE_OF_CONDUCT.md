# Code of Conduct

## Our pledge

We want participation in the GTFS Analyzer community to be a respectful and
harassment-free experience for everyone, regardless of background or identity.

## Our standards

We expect everyone interacting in the project's spaces (issues, pull requests, reviews,
and discussions) to:

- Be respectful, considerate, and constructive.
- Welcome differing viewpoints and accept constructive feedback gracefully.
- Focus on what is best for the project and the community.

Behavior that is disrespectful, harassing, or otherwise unwelcome is not tolerated.

## Adopted standard

This project adopts the **[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)**
as its full code of conduct. Please refer to that document for the complete standards,
scope, and enforcement guidelines.

## Reporting

If you experience or witness unacceptable behavior, please report it privately:

- **Preferred:** GitHub's private reporting on this repository (**Security → Report a
  vulnerability** is for security; for conduct issues, contact the maintainer directly).
- **Email:** ttezer@gmail.com

Reports will be handled confidentially. Maintainers are responsible for clarifying
standards and may take appropriate action, including removing comments, commits, or
contributions that violate this Code of Conduct.
