GTFS Validator privacy

When you use the GTFS Validator plugin, an uploaded feed or public feed URL is temporarily processed by the GTFS Validator service using the GTFS Analyzer engine.

The service does not intentionally retain feed contents, validation reports, or full source URLs after processing. Operational diagnostics use limited metadata such as duration, status, input size, and engine version. Signed download URLs and query strings are excluded from HTTP client logs.

The browser-based GTFS Analyzer is a separate local/WASM path: files opened there are processed in your browser and are not uploaded by the web application.
