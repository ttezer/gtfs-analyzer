GTFS Validator privacy

What we process

When you use the GTFS Validator plugin, the service temporarily processes an uploaded GTFS feed or a public GTFS feed URL using the GTFS Analyzer engine. Processing may include the feed files needed for validation and the URL or file metadata required to complete the request.

Retention and deletion

Feed contents, validation reports, and temporary analyzer configuration files are processed for the duration of the request and are not intentionally retained after processing. Temporary files used for URL context are deleted during request cleanup.

Operational diagnostics may include limited metadata such as request status, duration, input size, error type, and engine version. Raw feed contents, signed download URLs, and URL query strings are excluded from application request logs. Infrastructure providers may retain operational logs according to their own policies.

Sharing and use

GTFS Validator does not sell feed data or use submitted feeds for advertising. The service sends the requested public feed to the validator running on Google Cloud infrastructure and returns the resulting analysis to the requesting ChatGPT session. Do not submit credentials, private URLs, or data that you are not authorized to process.

Your choices and contact

You can avoid submitting a feed to the plugin and use the browser-based GTFS Analyzer instead. Files opened there are processed in your browser and are not uploaded by the web application. For privacy questions or deletion requests, contact the maintainer through the GTFS Analyzer issue tracker; do not include feed contents, signed URLs, credentials, or private data.
