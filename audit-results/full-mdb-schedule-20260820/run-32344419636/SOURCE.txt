A REGRESSION THIS RUN CAUGHT
-----------------------------
STP_036 fired 14 times on tfs-535, an archive with an unchanged SHA-256, having fired 0
times in run 32311885577. Cause: the STP_009 fix moved `parent` to the raw field value,
and three sibling `is_empty()` checks in the same block were not converted, so a
parent_station holding a single space counted as populated.

raw value. Verified on tfs-535 at the same SHA — 14 -> 0 — with mdb-2003's STP_009 still
at 0. Two regression tests pin both directions.
