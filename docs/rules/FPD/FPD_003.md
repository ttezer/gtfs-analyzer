# FPD_003 — currency geçersiz ISO 4217 kodu

> **Karar:** `fare_products.txt.currency` üç harfli büyük harf para birimi kodu biçiminde değil. KRİTİK, spec hatası. **Düzeltme:** `TRY`, `EUR`, `USD` gibi 3 harfli büyük ISO 4217 kodu kullanın.
> ⚠️ Kod yalnızca biçimsel kontrol yapar: uzunluk 3 ve ASCII büyük harf. Kodun aktif ISO 4217 listesinde gerçekten var olup olmadığı ayrıca doğrulanmaz.

## Tetikleme koşulu (kesin mantık)
`fare_products::validate_fare_products()` içinde:
```
currency.len() != 3
VEYA currency tüm karakterleri ASCII büyük harf değil
→ FPD_003
```
- Boş değer uzunluk kontrolüne takılır.
- `try`, `TR`, `TRY1` geçersizdir.

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** `ABC` gibi üç büyük harfli ama gerçek ISO 4217 kodu olmayan değerler kod seviyesinde geçebilir.
- **Yanlış pozitif:** Küçük harfli geçerli kod (`try`) spec biçimine uymadığı için hata sayılır.
