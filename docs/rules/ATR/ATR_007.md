# ATR_007 — attribution_url geçersiz / trip_id bulunamadı

> **Karar:** K2'de `attribution_url` geçerli `http/https` URL biçiminde olmalıdır; K4'te `trip_id` doluysa `trips.txt` içinde bulunmalıdır. KRİTİK, Spec.
> ⚠️ Registry başlığı `attribution_url geçersiz` der; mevcut kod aynı `ATR_007` ID'sini K4'te `trip_id` referans hatası için de üretir.

## Tetikleme koşulu (kesin mantık)
İki ayrı emit yolu vardır:

```text
K2: attribution_url dolu
VE looks_like_url(url) false
→ ATR_007

K4: attributions.txt.trip_id dolu
VE trip_id trips.txt içinde yok
→ ATR_007
```

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** Boş `attribution_url` hata değildir.
- **Yanlış pozitif:** URL biçimsel olarak geçerli olsa bile gerçekten açılıp açılmadığı kontrol edilmez; `trip_id` tarafında ise dış sistemde var olması yeterli değildir, feed içinde `trips.txt` gerekir.
