# ATR_011 — route_id bulunamadı

> **Karar:** `attributions.txt.route_id` doluysa `routes.txt` içinde tanımlı bir `route_id` değerini göstermelidir. DÜŞÜK, Spec.
> 📌 Bu yol 2026-08-01'e kadar [ATR_006](ATR_006.md) (`is_authority geçersiz`) ID'si altında raporlanıyordu — kullanıcı, bozuk bir `route_id` için "is_authority geçersiz" başlıklı bulgu alıyordu. Ayrıldı.

| Alan | Değer |
|---|---|
| Grup | ATR — Attributions |
| Önem | Düşük |
| Sınıf | Spec |
| Aşama | K4 |
| Varlık | Entity |
| Kimlik alanı | `attribution_id` |
| Skor tabanı | 1 |
| Görünürlük | VS (`R2`, `R5`, `R9`) |
| Bloke ettiği kurallar | - |

## Tetikleme koşulu (kesin mantık)
```text
K4: attributions.txt.route_id dolu
VE route_id EntityMap.routes içinde yok
→ ATR_011
```

`RTS_001` (route_id yineleniyor) bu kuralı bloke eder: route kimlikleri zaten tutarsızsa
referans hatası türev bir bulgudur.

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** `route_id` boşsa kural çalışmaz; attribution kapsamı agency/trip veya feed geneli olabilir.
- **Yanlış pozitif:** Hat dış sistemde var olsa bile feed içindeki `routes.txt` içinde yoksa GTFS referansı kopuktur — yanlış pozitif değildir.

## Neden DÜŞÜK (ATR_006'nın KRİTİK'inden farklı)
Emsal `ATR_010`'dur (aynı dosyanın `agency_id` referansı, DÜŞÜK). Yayın kapısı kaybı yoktur:
feed-level özet `XFL_015` (KRİTİK, `VS_K`) üç referans alanını da kapsar, dolayısıyla bozuk
referans taşıyan feed R1'de yine düşer. Eski KRİTİK değeri bu olgunun kendi kararı değil,
`is_authority` enum kuralının ağırlığının paylaşılmasından doğan artıktı.

- **Kural mesajı:** route_id bulunamadı
- **Çözüm önerisi:** `routes.txt` içinde var olan bir `route_id` kullanın.

### R2 mesajı/mesajları
- **Ayrıntılı bulgu mesajı:** *"'<route_id>' hattı routes.txt'te tanımlı değil."*

## Ölçülen alan / değer
- **Dosya/alan:** `attributions.txt` → `route_id`
- **Gözlenen değer:** bulunamayan route id
- **Beklenen değer:** `routes.txt` içinde mevcut `route_id`

## Kod değiştirirken minimum test matrisi
- `route_id` boş → ATR_011 çıkmamalı.
- `route_id` routes.txt'te var → ATR_011 çıkmamalı.
- `route_id` routes.txt'te yok → ATR_011 çıkmalı.
- `is_authority=2` → ATR_011 **çıkmamalı** (o ATR_006).
