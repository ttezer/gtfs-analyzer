# STP_013 — wheelchair_boarding geçersiz

> Karar: `wheelchair_boarding` verildiyse sayısal olarak okunabilmeli ve `0`, `1` veya `2` olmalıdır.

| Alan | Değer |
|---|---|
| Grup | STP — Stops |

| Varlık | Entity |
| Kimlik alanı | `stop_id` |
| Skor tabanı | 1 |
| Görünürlük | VS_ACC (`R2`, `R5`, `R7`, `R9`) |
| Bloke ettiği kurallar | - |

## Tetikleme koşulu (kesin mantık)
K2 `wheelchair_boarding` alanını `u32` olarak parse eder. Parse edilemeyen değerlerde veya parse edilen değer `0`, `1` veya `2` değilse STP_013 üretilir.

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** Yok; dolu ve parse edilemeyen değerler STP_013 üretir.
- **Yanlış pozitif:** Boş değer GTFS'te bilinmiyor anlamına gelebildiği için hata değildir.
