# STP_023 — tts_stop_name geçersiz

> Karar: `tts_stop_name` HTML/SSML işaret karakteri gibi yorumlanabilecek `<` veya `>` karakterlerini içermemelidir.
> ⚠️ Bu kontrol TTS metninin tüm telaffuz kalitesini değil, yalnızca `<` ve `>` işaret karakterlerini yakalar.

| Alan | Değer |
|---|---|
| Grup | STP — Stops |
| Önem | Düşük |
| Sınıf | Quality |
| Aşama | K2 |
| Varlık | Entity |
| Kimlik alanı | `stop_id` |
| Skor tabanı | 1 |
| Görünürlük | VS (`R2`, `R5`, `R9`) |
| Bloke ettiği kurallar | - |

## Tetikleme koşulu (kesin mantık)
K2 `tts_stop_name` alanı doluysa değerin içinde `<` veya `>` karakteri arar. Bu karakterlerden biri varsa STP_023 üretilir.

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** Başka okunabilirlik sorunları bu kuralın kapsamı değildir.
- **Yanlış pozitif:** Gerçek ad içinde bu karakterler nadiren gerekebilir; TTS alanında işaret dili riski daha baskındır.
