# STP_010 — parent_station location_type=1 değil

> Karar: `parent_station` ile gösterilen kayıt istasyon olmalı, yani `location_type=1` taşımalıdır.
> ⚠️ Bu kural yalnızca parent kayıt bulunabildiğinde çalışır; parent id hiç yoksa önce STP_009 kök neden kabul edilmelidir.

| Alan | Değer |
|---|---|
| Grup | STP — Stops |
| Önem | Yüksek |
| Sınıf | Spec |
| Aşama | K4 |
| Varlık | Entity |
| Kimlik alanı | `stop_id` |
| Skor tabanı | 1 |
| Görünürlük | VS (`R2`, `R5`, `R9`) |
| Bloke ettiği kurallar | - |

## Tetikleme koşulu (kesin mantık)
K4 önce `parent_station` değerinin varlığını doğrular. Parent kayıt bulunduysa ama parent kaydın `location_type` değeri `1` değilse STP_010 üretilir.

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** Parent hiç yoksa STP_009 üretir; STP_010 çalışmaz.
- **Yanlış pozitif:** Fiziksel platformu parent olarak kullanmak GTFS hiyerarşisine göre geçerli değildir.

## Mesaj & çözüm önerisi
### R9 Kural Mesajı
- **Kural mesajı:** parent_station location_type=1 değil
- **Çözüm önerisi:** `parent_station` olarak sadece `location_type=1` olan istasyonları kullanın.

### R2 mesajı/mesajları
- **Ayrıntılı bulgu mesajı:** *"'<parent>' istasyonunun location_type'ı 1 (station) olmalı."*
- **Ayrıntılı çözüm:** *"parent_station olarak yalnızca location_type=1 olan duraklarla referans verin."*

## Ölçülen alan / değer
- `file`: `stops.txt`
- `field`: `parent_station`
- `line`: ilgili satır
- `observed`: station olmayan parent
- `expected`: parent `location_type=1`
