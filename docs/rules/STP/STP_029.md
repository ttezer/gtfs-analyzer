# STP_029 — Durak istasyon içinde ama koordinat çok uzakta

> Karar: Bir platform parent istasyona bağlıysa koordinatı istasyondan yapılandırılmış mesafe eşiğinin ötesine düşmemelidir.
> ⚠️ Bu kural koordinatları ve parent referansı geçerli olan fiziksel duraklarda çalışır; eşik `config.stop_far_from_parent_m` değerine bağlıdır.

| Alan | Değer |
|---|---|
| Grup | STP — Stops |
| Önem | Orta |
| Sınıf | Quality |
| Aşama | K6 |
| Varlık | Entity |
| Kimlik alanı | `stop_id` |
| Skor tabanı | 2 |
| Görünürlük | VS (`R2`, `R5`, `R9`) |
| Bloke ettiği kurallar | - |

## Tetikleme koşulu (kesin mantık)
K6 fiziksel durakları (`location_type` boş veya `0`) gezer. Durakta `parent_station` varsa ve hem durak hem parent koordinatları doluysa mesafeyi hesaplar. Mesafe `config.stop_far_from_parent_m` eşiğini aşarsa STP_029 üretilir.
- **Varsayılan eşik 150m** (önceki 100m'den yükseltildi): otobüs garaj/terminal parent istasyonlarında çocuk durak merkeze 100–150m düşebilir; 100m bu meşru yapılarda kitlesel FP üretiyordu (Tokyo'da medyan 130m, %69'u 100–150m bandında).
- **Önem Orta** (önceki Yüksek'ten düşürüldü): bu bir mesafe-heuristiği (Quality), spec ihlali değil; HIGH yayın skorunu orantısız vuruyordu.

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** Parent veya durak koordinatı eksikse mesafe hesaplanamaz; K2 koordinat kuralları beklenir.
- **Yanlış pozitif:** Çok büyük terminal/garaj istasyonlarında eşik (150m) hâlâ düşük kalabilir; configurable. Bulgular *yanlış* değil (durak gerçekten uzakta) — eşik/önem kalibrasyonu gürültüyü dengeler.

## Mesaj & çözüm önerisi
### R9 Kural Mesajı
- **Kural mesajı:** Durak istasyon içinde ama koordinat çok uzakta
- **Çözüm önerisi:** Durak koordinatını veya `parent_station` referansını düzeltin.

### R2 mesajı/mesajları
- **Ayrıntılı bulgu mesajı:** *"'<stop_id>' kodlu '<name>' durağı üst istasyonundan (<parent_id>) <dist_m>m uzakta (eşik: <threshold>m)."*
- **Ayrıntılı çözüm:** *"Durak koordinatlarını veya parent_station referansını düzeltin."*

## Ölçülen alan / değer
- `file`: `stops.txt`
- `field`: `stop_lat|stop_lon|parent_station`
- `line`: ilgili durak satırı
- `observed`: parent'a mesafe
- `expected`: `<= config.stop_far_from_parent_m`
