# STP_016 — İki durak tam aynı koordinatta

> Karar: İki farklı `stop_id` aynı enlem/boylam noktasına birebir düşüyorsa kalite sorunu olarak raporlanır.
> ⚠️ Bu kural yalnızca geçerli koordinatı olan durak çiftlerini karşılaştırır; koordinat eksik/parse hatalıysa önce K2 koordinat kuralları çalışmalıdır.

| Varlık | Entity |
| Kimlik alanı | `stop_id` |
| Skor tabanı | 2 |
| Görünürlük | VS (`R2`, `R5`, `R9`) |
| Bloke ettiği kurallar | - |

## Tetikleme koşulu (kesin mantık)
K6 koordinatı olan durak çiftlerini karşılaştırır. Haversine mesafesi `0` ise ilk durağın kimliğiyle STP_016 üretilir.

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** Koordinat eksik veya parse edilemezse bu kural çalışmaz; önce K2 koordinat kuralları beklenir.
- **Yanlış pozitif:** Aynı fiziksel noktada iki ayrı platform bilinçli modellenmiş olabilir; yine de kullanıcı deneyimi açısından incelenmelidir.

## Mesaj & çözüm önerisi
### R9 Kural Mesajı
- **Kural mesajı:** İki durak tam aynı koordinatta
- **Çözüm önerisi:** Aynı fiziksel duraksa kayıtları birleştirin; farklı duraksa koordinatları düzeltin.

### R2 mesajı/mesajları
- **Ayrıntılı bulgu mesajı:** *"'<name_a>' (kod: '<id_a>') ve '<name_b>' (kod: '<id_b>') tam olarak aynı koordinatta (<lat>, <lon>)."*
- **Ayrıntılı çözüm:** *"İki durak aynı konumdaysa birleştirin; farklı duraklar ise koordinatları düzeltin."*

## Ölçülen alan / değer
- `file`: `stops.txt`
- `field`: `stop_lat|stop_lon`
- `line`: ilk durak satırı
- `observed`: aynı koordinat ve karşı durak id'si

## Kod değiştirirken minimum test matrisi
| Senaryo | Beklenen |

| iki durak birebir aynı koordinatta | `STP_016` |
