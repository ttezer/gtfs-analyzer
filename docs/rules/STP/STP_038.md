# STP_038 — Hiçbir durak tekerlekli sandalye erişilebilirliği (wheelchair_boarding) bildirmemiş

> **Karar:** Hiçbir fiziksel durakta (location_type 0 veya boş) `wheelchair_boarding` dolu değil; erişilebilirlik verisi tümüyle eksik (Cal-ITP ACC-1). BİLGİ, Quality. **Düzeltme:** Durakların tekerlekli sandalye erişilebilirliğini `wheelchair_boarding` ile bildirin (1=erişilebilir, 2=erişilemez).
> ⚠️ Yalnız fiziksel duraklar sayılır. Bazıları doluysa STP_037, hepsi doluysa notice yok.

## Tetikleme koşulu (kesin mantık)
`k6_analytics::check_operational_analytics()` içinde:
```
total = location_type ∈ {None, 0} olan durak sayısı (fiziksel duraklar)
unset = bunlardan wheelchair_boarding ∈ {None, 0} olanlar
unset == total (total > 0)
→ STP_038 (feed-level notice)
```
- Kapsam birimi: feed.

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** Bazı duraklar doluysa STP_037 (bu kural değil) çıkar.
- **Yanlış pozitif:** Küçük/erken feed'lerde erişilebilirlik henüz bildirilmemiş olabilir; BİLGİ önemi bu yüzden seçildi.
