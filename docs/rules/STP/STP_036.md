# STP_036 — İstasyonun parent_station'ı var

> Karar: `location_type=1` olan istasyon üst varlıktır; kendi `parent_station` değerini taşımamalıdır.
> ⚠️ Bu kural yalnızca station kaydının kendi parent'ını yasaklar; station'ın hiç alt durağı olmaması STP_030 ile ayrı değerlendirilir.

| Alan | Değer |
|---|---|
| Grup | STP — Stops |
| Önem | Düşük |
| Sınıf | Spec |
| Aşama | K4 |
| Varlık | Entity |
| Kimlik alanı | `stop_id` |
| Skor tabanı | 1 |
| Görünürlük | VS (`R2`, `R5`, `R9`) |
| Bloke ettiği kurallar | - |

## Tetikleme koşulu (kesin mantık)
K4 `location_type=1` olan kayıtları istasyon kabul eder. Bu kayıtta `parent_station` alanı doluysa STP_036 üretilir.

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** Parent ilişkisi başka alanda ifade edilmişse bu kural bakmaz.
- **Yanlış pozitif:** İç içe istasyon modeli iş gereği istenebilir; GTFS `parent_station` hiyerarşisinde istasyon üst varlık olduğu için bu kullanım geçersizdir.

## Mesaj & çözüm önerisi
### R9 Kural Mesajı
- **Kural mesajı:** İstasyonun (location_type=1) parent_station'ı var
- **Çözüm önerisi:** İstasyon satırından `parent_station` değerini kaldırın.

### R2 mesajı/mesajları
- **Ayrıntılı bulgu mesajı:** *"İstasyon '<id>' (location_type=1) parent_station='<parent>' içeriyor; istasyonlar üst varlık olarak parent_station içermemelidir."*
- **Ayrıntılı çözüm:** *"İstasyondan parent_station alanını kaldırın; sadece location_type 2/3/4 için parent_station gerekir."*

## Ölçülen alan / değer
- `file`: `stops.txt`
- `field`: `parent_station`
- `line`: istasyon satırı
- `observed`: station üzerinde parent id
- `expected`: boş `parent_station`
