# STP_025 — stop_name baştaki veya sondaki boşluk içeriyor

> Karar: `stop_name` değerinin başında veya sonunda boşluk kalmamalıdır.
> ⚠️ Bu kural adın ortasındaki çift boşlukları veya yazım kalitesini yakalamaz; yalnızca ham değer ile trim edilmiş değer farkına bakar.

| Alan | Değer |
|---|---|
| Grup | STP — Stops |
| Önem | Orta |
| Sınıf | Quality |
| Aşama | K2 |
| Varlık | Entity |
| Kimlik alanı | `stop_id` |
| Skor tabanı | 1 |
| Görünürlük | VS (`R2`, `R5`, `R9`) |
| Bloke ettiği kurallar | - |

## Tetikleme koşulu (kesin mantık)
K2 ham `stop_name` alanı boş değilken trim edilmiş değerle ham değer farklıysa STP_025 üretir. Yani baştaki veya sondaki boşluklar yakalanır.

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** Adın ortasındaki çift boşluklar bu kuralın kapsamı değildir.
- **Yanlış pozitif:** Kullanıcı arayüzünde görünmeyen boşluklar sıralama/arama sorununa yol açabileceği için bilinçli bırakılmamalıdır.
