# SHP_010 — Tekrarlanan shape noktası (ardışık özdeş koordinat)

> **Karar:** Bir shape içinde ardışık iki nokta birebir aynı koordinata sahip; gereksiz/yinelenen nokta. DÜŞÜK, Quality. **Düzeltme:** Tekrarlanan güzergah noktasını kaldırın.
> ⚠️ K5 geometri kurulumunda, yalnızca **ardışık** özdeş koordinatlar (`< f64::EPSILON`) yakalanır; pencere içi (ardışık olmayan) tekrarlar SHP_020 kapsamındadır.

| Alan | Değer |

| Grup | SHP — Shapes |
| Önem | Düşük |
| Sınıf | Quality |
| Aşama | K5 |
| Varlık | Entity |
| Kimlik alanı | `shape_id` |
| Skor tabanı | 1 |
| Görünürlük | VS (`R2`, `R5`, `R9`) |
| Bloke ettiği kurallar | - |

## Tetikleme koşulu (kesin mantık)
`k5_derived::build_shape_geometry()` içinde:
```
ardışık nokta çiftinde |lat - plat| < EPSILON VE |lon - plon| < EPSILON
→ SHP_010 (satır bazlı notice)
```
- Kapsam birimi: shape (Entity).

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** Ardışık olmayan tekrarlar (ör. nokta 1 ve 5 aynı) SHP_010 değil SHP_020 ile yakalanır.
- **Yanlış pozitif:** Yok denecek kadar az; özdeş ardışık nokta gereksizdir.
