# SHP_012 — Güzergah şekli sefer duraklarından çok uzak

> **Karar:** Bir shape, kendisini kullanan seferlerin duraklarının çoğundan **`config.stop_far_from_shape_m`** (vars. 100 m)'den fazla uzakta; güzergah yanlış çizilmiş olabilir. YÜKSEK, Analytics. **Düzeltme:** `shapes.txt` noktalarını durak konumlarına yaklaştırın.
> ⚠️ Eşik config `stop_far_from_shape_m` (vars. 100 m); shape başına eşiği aşan durak sayısı sayılır. Bounding-box ön elemesi + nokta-polyline mesafesi kullanılır.

## Tetikleme koşulu (kesin mantık)
`k6_analytics::check_shp012()` içinde:
```
shape'i kullanan seferlerin durakları için
min(stop → shape polyline) mesafesi > config.stop_far_from_shape_m (vars. 100m) olan durak sayısı sayılır
sayı > 0 → SHP_012 (shape bazlı notice)
```
- Eşik: **`config.stop_far_from_shape_m`** (vars. **100 m**; önceki 500 m hardcoded hataydı).

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** Durak/shape koordinatı eksikse mesafe hesaplanmaz.
- **Yanlış pozitif:** Ekspres segmentlerde durağa uğramayan shape bölümleri meşru olabilir; eşik sezgiseldir.
