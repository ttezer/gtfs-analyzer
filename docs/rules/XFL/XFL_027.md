# XFL_027 — route cemv_support=2 ama uygulanabilir contactless fare product var

> **Karar:** Bir route `route_cemv_support=2` (contactless desteklenmiyor) diyor, ancak Fares v2 zincirinde o route'a UYGULANABİLİR contactless fare product (`fare_media_type=3`) var — çelişki. ORTA, Quality. **Düzeltme:** `cemv_support` değerini düzeltin veya contactless fare product kapsamını gözden geçirin.
> ⚠️ Route bazlı. Uygulanabilirlik: leg rule `network_id` boş (global) / `network_id`=route.network_id / `from/to_area_id` route'un alanlarıyla eşleşir.

## Tetikleme koşulu (kesin mantık)
`k4_cross_ref::check()`: `fare_media(type=3) → fare_products → fare_leg_rules` zincirinden type3 leg rule kapsamı çıkarılır. Bir route için:
```
route.cemv_support=2 VE route KAPSANIYOR (global VEYA network eşleşir VEYA area eşleşir)
→ XFL_027
```

## Yanlış pozitif / negatif (asıl tasarım riski)
- **FP düşük:** yalnız KESİN kapsama (global/network/area eşleşmesi) tetikler; belirsizlikte tetiklenmez.
- **Yanlış negatif:** area zinciri eksikse area-eşleşmeli kapsama görülmeyebilir (konservatif).
