# XFL_025 — location_id bulunamadı (locations.geojson)

> **Karar:** `stop_times.txt::location_id` `locations.geojson`'da tanımlı bir feature id'sine karşılık gelmiyor. KRİTİK, Spec — Flex sefer bu bölgeye bağlanamaz. **Düzeltme:** Geçerli bir `location_id` kullanın veya konumu `locations.geojson`'a ekleyin.
> ⚠️ Satır bazlı (Row) FK; GTFS-Flex zone-based servis. geojson feature id'leri K1'de toplanır. Yalnızca flex sütunu olan feed'lerde değerlendirilir; aynı tanımsız id tek kez raporlanır (dedup).

## Tetikleme koşulu (kesin mantık)
`k4_cross_ref::check()` stop_times geçişinde:
```
stop_times.location_id boş değil VE map.geojson_location_ids İÇERMİYOR
→ XFL_025 (satır bazlı notice, location_id başına bir kez)
```
- `geojson_location_ids`: `locations.geojson` feature 'id' değerleri (K1'de toplanıp EntityMap'e enjekte edilir).
- Kapsam birimi: satır (Row), tanımsız `location_id` başına dedup.

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** `location_id` boşsa atlanır; locations.geojson yoksa id kümesi boş kalır ve her location_id raporlanır (doğru — dosya eksik).
- **Yanlış pozitif:** geojson feature id'si string olmayan (sayısal) ise ham CSV değeriyle eşleşmeyebilir; pratikte GTFS-Flex id'leri string.
