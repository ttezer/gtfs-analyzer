# XFL_031 — Kimlik çakışması: stop_id / locations.geojson id / location_group_id ortak isim alanını paylaşır

> **Karar:** Aynı kimlik değeri `stops.stop_id`, `locations.geojson` feature id ve `location_groups.location_group_id` kaynaklarından **birden fazlasında** geçiyor. KRİTİK, Spec — `stop_times.location_id` / `location_group_id` referansı hangi varlığa işaret ettiği belirsiz kalır. **Düzeltme:** Çakışan kimliklerden birini yeniden adlandırın.
> ⚠️ Spec (`location_groups.location_group_id`): *"ID must be unique across all `stops.stop_id`, `locations.geojson` id, and `location_groups.location_group_id` values."* Üç dosya TEK bir isim alanı paylaşır.

## Tetikleme koşulu (kesin mantık)
`k4_cross_ref::check()` içinde:
```
her location_group_id için:
    stops.stop_id kümesinde VAR            → çakışma (kaynak: stops.stop_id)
    değilse geojson feature id'de VAR      → çakışma (kaynak: locations.geojson id)
her geojson feature id için:
    stops.stop_id kümesinde VAR            → çakışma
→ XFL_031 (çakışan kimlik başına TEK notice; liste sıralanır + dedup edilir)
```
- Boş kimlikler atlanır (varlık/zorunluluk ayrı kuralların konusu).
- Determinizm: kümeler sırasız olduğundan çakışmalar emisyondan önce sıralanır.

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** Kimliklerden biri boşsa değerlendirilmez. `locations.geojson` ayrıştırılamamışsa (LOC_001/LOC_002) id kümesi boş kalır ve o kaynak karşılaştırmaya girmez.
- **Yanlış pozitif:** Yok denecek kadar az — spec kısıtı mutlaktır, "aynı değer iki kaynakta" tek başına ihlaldir. Bilinçli aynı-adlandırma bile referansı belirsizleştirdiği için geçerli değildir.
