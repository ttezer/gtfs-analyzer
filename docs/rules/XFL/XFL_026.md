# XFL_026 — route cemv_support=1 ama uygulanabilir contactless fare product yok

> **Karar:** Bir route `route_cemv_support=1` (contactless destekleniyor) diyor, ancak Fares v2 zincirinde o route'a UYGULANABİLİR contactless fare product (`fare_media_type=3`) yok. ORTA, Interop. **Düzeltme:** Bu route'a uygulanabilir bir contactless fare product tanımlayın veya `cemv_support` değerini gözden geçirin.
> ⚠️ Route bazlı. Uygulanabilirlik 3 yoldan biriyle: leg rule `network_id` boş (global) / `network_id`=route.network_id / `from/to_area_id` route'un alanlarıyla eşleşir.

## Tetikleme koşulu (kesin mantık)
`k4_cross_ref::check()`: `fare_media(type=3) → fare_products → fare_leg_rules` zincirinden type3 leg rule kapsamı (global / network / area) çıkarılır. Bir route için:
```
route.cemv_support=1 VE route ÇÖZÜLEBİLİR (global VEYA network_id dolu VEYA area bilinir)
VE route KAPSANMIYOR (global yok && network eşleşmiyor && area eşleşmiyor)
→ XFL_026
```

## Yanlış pozitif / negatif (asıl tasarım riski)
- **FP guard:** route'un kapsamı çözülemiyorsa (network_id boş + durak/area bilinmiyor) SUSAR — şüphede "kapsanıyor" sayılır.
- **Yanlış negatif:** route→area zinciri stop_times eksikse alanlar bilinmez; konservatif guard nedeniyle tetiklenmez (FP yerine FN tercih edildi).
