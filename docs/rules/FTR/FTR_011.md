# FTR_011 — duration_limit tanımlı ama duration_limit_type eksik

> **Karar:** `duration_limit` dolu ama `duration_limit_type` boş. GTFS spec: `duration_limit_type`, `duration_limit` tanımlıyken zorunludur. ORTA, Spec. **Düzeltme:** `duration_limit_type` alanını (0–3) doldurun ya da `duration_limit`'i kaldırın.
> ⚠️ FTR_007'nin ters yönüdür (FTR_007 = type dolu/limit boş). İkisi birlikte duration alanı çiftinin tutarlılığını garanti eder.
