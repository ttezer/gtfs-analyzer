# FTR_010 — leg grupları farklıyken transfer_count tanımlanamaz

> **Karar:** `from_leg_group_id` ile `to_leg_group_id` farklı iken `transfer_count` tanımlanamaz (yasak); doluysa FTR_010. ORTA, Spec. **Düzeltme:** `transfer_count` alanını kaldırın ya da leg gruplarını eşitleyin.

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** Leg gruplarından biri boşsa kural uygulanmaz (global/area kuralı kabul edilir).
- **Yanlış pozitif:** Spec açıkça yasakladığından, farklı leg grupları arası transfer_count veri modeli hatasıdır.
