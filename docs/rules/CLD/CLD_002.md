# CLD_002 — date eksik veya geçersiz format

> **Karar:** `calendar_dates.txt` satırında `date` yok veya `YYYYMMDD` servis tarihi olarak parse edilemiyor. KRİTİK, yayın engelleyici. **Düzeltme:** `date` alanını geçerli `YYYYMMDD` formatında doldurun.
> ⚠️ Bu kural tarihin makul yıl aralığında olup olmadığını değil, varlık ve formatını kontrol eder; 2000-2099 aralığı CLD_005 konusudur.
