# DQ_001 — Feed adı eksik

> Karar: İçerik barındıran feed'de `feed_info.feed_publisher_name` boş kalmamalıdır.
> ⚠️ Feed tamamen boşsa bu kural çalışmaz.

| Alan | Değer |
|---|---|
| Grup | DQ — Veri Kalitesi |
| Önem | Düşük |
| Sınıf | Quality |
| Aşama | K6 |
| Varlık | Feed |
| Kimlik alanı | - |
| Skor tabanı | 1 |
| Görünürlük | VS (`R2`, `R5`, `R9`) |
| Bloke ettiği kurallar | - |

## Tetikleme koşulu (kesin mantık)
K6 önce feed'in gerçek içerik barındırıp barındırmadığını kontrol eder: agency, route, stop veya trip kayıtlarından en az biri varsa `feed_has_content=true` olur.

Bu durumda `feed_info.txt` içindeki ilk kayıtta `feed_publisher_name` yoksa veya trim sonrası boşsa DQ_001 üretilir. `feed_info.txt` tamamen yoksa da aynı koşul boş kabul edilir.

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** Feed tamamen boşsa bu kural çalışmaz.
- **Yanlış pozitif:** Test feed'lerinde yayıncı adı bilinçli boş bırakılabilir; kalite uyarısı olarak tutulur.

## Mesaj & çözüm önerisi
### R9 Kural Mesajı
- **Kural mesajı:** Feed adı eksik
- **Çözüm önerisi:** `feed_info.txt` dosyasına yayıncıyı tanımlayan `feed_publisher_name` değeri ekleyin.

### R2 mesajı/mesajları
- **Ayrıntılı bulgu mesajı:** *"feed_publisher_name belirtilmemiş — feed kaynağı tanımlanamıyor."*
- **Ayrıntılı çözüm:** *"feed_info.txt dosyasına feed_publisher_name ekleyin."*

## Ölçülen alan / değer
- `file`: `feed_info.txt`
- `field`: `feed_publisher_name`
- `line`: feed seviyesi
