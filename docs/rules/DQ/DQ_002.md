# DQ_002 — feed_publisher_url eksik

> Karar: İçerik barındıran feed'de `feed_info.feed_publisher_url` boş kalmamalıdır.
> ⚠️ Feed boşsa uyarı üretilmez.

| Alan | Değer |
|---|---|
| Grup | DQ — Veri Kalitesi |
| Önem | Düşük |
| Sınıf | Quality |
| Aşama | K6 |
| Varlık | Feed |
| Kimlik alanı | - |
| Skor tabanı | 1 |
| Görünürlük | VS (`R2`, `R5`, `R9`) |
| Bloke ettiği kurallar | - |

## Tetikleme koşulu (kesin mantık)
K6 `feed_has_content` kontrolü true ise `feed_info.txt` içindeki ilk kayıtta `feed_publisher_url` alanını arar.

Alan yoksa veya trim sonrası boşsa DQ_002 üretilir. Bu kural URL formatını değil, URL'nin varlığını kontrol eder.

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** Feed boşsa uyarı üretilmez.
- **Yanlış pozitif:** Yayıncı URL'si olmayan küçük/test feed'lerinde kalite uyarısı beklenebilir.
