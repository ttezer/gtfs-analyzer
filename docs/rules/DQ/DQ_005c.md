# DQ_005c — Koordinatsız durak oranı çok yüksek

> Karar: Durakların yarısından fazlasında koordinat yoksa coğrafi analiz ve harita deneyimi ciddi biçimde zayıflar.
> ⚠️ Durak listesi boşsa bu kural çalışmaz.

| Alan | Değer |
|---|---|
| Grup | DQ — Veri Kalitesi |
| Önem | Yüksek |
| Sınıf | Interop |
| Aşama | K6 |
| Varlık | Feed |
| Kimlik alanı | - |
| Skor tabanı | 2 |
| Görünürlük | VI_K (`R1`, `R2`, `R5`, `R8`, `R9`) |
| Bloke ettiği kurallar | - |

## Tetikleme koşulu (kesin mantık)
K6 durak listesi boş değilse `stop_lat` veya `stop_lon` alanı eksik olan durakları sayar.

Eksik koordinat oranı `> 0.5` ise DQ_005c üretilir.

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** Durak listesi boşsa bu kural çalışmaz.
- **Yanlış pozitif:** Bazı geçici/import feed'lerde koordinatlar sonradan ekleniyor olabilir; harita/interop açısından yine yüksek risklidir.

## Mesaj & çözüm önerisi
### R9 Kural Mesajı
- **Kural mesajı:** Koordinatsız durak oranı çok yüksek
- **Çözüm önerisi:** Durakların `stop_lat` ve `stop_lon` alanlarını doldurun.

### R2 mesajı/mesajları
- **Ayrıntılı bulgu mesajı:** *"Duraksaların %<oran>'ında koordinat eksik — coğrafi analiz kısıtlı."*

## Ölçülen alan / değer

- `observed`: `%<oran> koordinatsız durak`
- `expected`: `≤ %50`
