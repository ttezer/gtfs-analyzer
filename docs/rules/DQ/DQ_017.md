# DQ_017 — Şüpheli koordinat değeri

> Karar: Çok sayıda durak `(0,0)` civarında görünüyorsa koordinatlar muhtemelen placeholder veya hatalıdır.
> ⚠️ Koordinatları başka yanlış noktaya kaymış duraklar bu kuralda yakalanmaz.

| Alan | Değer |
|---|---|
| Grup | DQ — Veri Kalitesi |
| Önem | Bilgi |
| Sınıf | Quality |
| Aşama | K6 |
| Varlık | Feed |
| Kimlik alanı | - |
| Skor tabanı | 1 |
| Görünürlük | VS (`R2`, `R5`, `R9`) |
| Bloke ettiği kurallar | - |

## Tetikleme koşulu (kesin mantık)
K6 `stop_id` boş olmayan durakları gezer.

`stop_lat` ve `stop_lon` ikisi de varsa ve mutlak değerleri `1.0` dereceden küçükse durak şüpheli sayılır. Şüpheli durak sayısı 0'dan büyükse DQ_017 feed seviyesinde tek notice üretir.

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** Koordinatları başka yanlış noktaya kaymış duraklar bu kuralda yakalanmaz.
- **Yanlış pozitif:** Gerçekten ekvator ve Greenwich yakınında çalışan feed olabilir; mesaj bu yüzden “şüpheli”dir.
