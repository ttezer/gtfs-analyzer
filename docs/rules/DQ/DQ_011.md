## Tetikleme koşulu (kesin mantık)
K6 `records.stops.len() == 1` ise DQ_011 üretir.

Sıfır durak bu kuralın konusu değildir; zorunlu dosya/alan veya başka kapsam kuralları devreye girer.

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** 0 durak durumunu yakalamaz.
- **Yanlış pozitif:** Tek duraklı test feed'i olabilir; gerçek transit yayını için yetersizdir.
