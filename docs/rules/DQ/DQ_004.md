# DQ_004 — Hat URL'si eksik

> Karar: Route için yolcu bilgi sayfasına giden `route_url` boşsa **BİLGİ** düzeyinde kalite ipucu üretilir (skoru düşürmez).
> ⚠️ Dolu ama geçersiz URL bu kural değildir; route URL format kontrolü ayrı yerde ele alınır.
> ⚠️ Severity 2026-07-03'te DÜŞÜK→BİLGİ: `route_url` GTFS'te opsiyonel, MobilityData işaretlemez, kardeşi DQ_003 (route_desc) de BİLGİ — opsiyonel alan eksikliği skoru düşürmemeli.

## Tetikleme koşulu (kesin mantık)
K6 her route kaydını gezer. `route_id` boşsa atlar.

`route_url` alanı yoksa veya trim sonrası boşsa route başına DQ_004 üretilir. Bu kural URL formatını değil, alanın varlığını kontrol eder.

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** Dolu ama geçersiz URL bu kural değildir; route URL format kontrolü ayrı yerde ele alınır.
- **Yanlış pozitif:** Bazı feed'lerde hat bazlı web sayfası olmayabilir; kalite uyarısıdır.

## Mesaj & çözüm önerisi
### R9 Kural Mesajı
- **Kural mesajı:** Hat URL'si eksik
- **Çözüm önerisi:** Hat için web sayfası varsa `routes.txt.route_url` alanını doldurun.

### R2 mesajı/mesajları
- **Ayrıntılı bulgu mesajı:** *"'<route_id>' (<label>) hattında route_url alanı boş; yolcular hat web sayfasına yönlendirilemiyor."*
