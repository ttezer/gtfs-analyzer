# DQ_005 — Geçerli servis dönemi yok

> Karar: Feed'de trip var ama bugün itibarıyla geleceğe uzanan aktif servis tarihi yoksa feed kullanılabilir görünmez.
> ⚠️ Trip yoksa bu kural çalışmaz.

| Alan | Değer |
|---|---|
| Grup | DQ — Veri Kalitesi |
| Önem | Yüksek |
| Sınıf | Interop |
| Aşama | K6 |
| Varlık | Feed |
| Kimlik alanı | - |
| Skor tabanı | 2 |
| Görünürlük | VI_K (`R1`, `R2`, `R5`, `R8`, `R9`) |
| Bloke ettiği kurallar | - |

## Tetikleme koşulu (kesin mantık)
K6 `derived.calendar_bitmap.active_dates` içindeki aktif tarihleri bugünün `yyyymmdd` değeriyle karşılaştırır.

`records.trips` boş değilse ve hiçbir servis için bugün veya sonrasında aktif tarih yoksa DQ_005 üretilir. `today_yyyymmdd` sıfırsa sadece active_dates map'inin boş olup olmadığına bakılır.

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** Trip yoksa bu kural çalışmaz.
- **Yanlış pozitif:** Feed bilinçli geçmiş arşiv olabilir; canlı yayın açısından interop blocker davranır.
