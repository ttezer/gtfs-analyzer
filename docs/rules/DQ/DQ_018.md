# DQ_018 — Önerilen alanda tamamen büyük harf

> Karar: Yolcuya gösterilen önerilen metin alanları tamamen büyük harfle yazılmışsa okunabilirlik düşer.
> ⚠️ Kısaltma içeren kısa metinler yakalanmayabilir veya yakalansa bile bağlama göre kabul edilebilir.

| Alan | Değer |
|---|---|
| Grup | DQ — Veri Kalitesi |
| Önem | Orta |
| Sınıf | Quality |
| Aşama | K6 |
| Varlık | Entity |
| Kimlik alanı | `stop_id` |
| Skor tabanı | 1 |
| Görünürlük | VS (`R2`, `R5`, `R9`) |
| Bloke ettiği kurallar | - |

## Tetikleme koşulu (kesin mantık)
K6 `is_all_caps` kontrolünü önerilen metin alanlarına uygular.

Kontrol edilen alanlar: `stops.stop_name`, `routes.route_long_name`, `routes.route_desc`, `trips.trip_headsign`, `agency.agency_name`, `feed_info.feed_publisher_name` ve `stop_times.stop_headsign`.

Tek harf ve harf içermeyen değerler all-caps sayılmaz; fonksiyon harf varlığı ve küçük harf yokluğu üzerinden karar verir.

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** Kısaltma içeren kısa metinler yakalanmayabilir veya yakalansa bile bağlama göre kabul edilebilir.
- **Yanlış pozitif:** Resmi marka adları tamamen büyük harf olabilir; kalite uyarısıdır.
