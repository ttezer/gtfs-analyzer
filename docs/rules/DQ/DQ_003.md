# DQ_003 — Hat açıklaması eksik

> Karar: Route için yolcuya ek bilgi veren `route_desc` alanı boşsa kalite uyarısı üretilir.
> ⚠️ `route_id` boş olan route'lar bu kuralda atlanır.

| Alan | Değer |
|---|---|
| Grup | DQ — Veri Kalitesi |
| Önem | Bilgi |
| Sınıf | Quality |
| Aşama | K6 |
| Varlık | Entity |
| Kimlik alanı | `route_id` |
| Skor tabanı | 1 |
| Görünürlük | VS (`R2`, `R5`, `R9`) |
| Bloke ettiği kurallar | - |

## Tetikleme koşulu (kesin mantık)
K6 her route kaydını gezer. `route_id` boşsa atlar.

`route_desc` alanı yoksa veya trim sonrası boşsa route başına DQ_003 üretilir.

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** `route_id` boş olan route'lar bu kuralda atlanır.
- **Yanlış pozitif:** Kısa/uzun hat adları yeterli bilgi veriyor olabilir; bu yüzden bilgi seviyesindedir.

- **Çözüm önerisi:** `routes.txt` içinde ilgili hatta kısa ve kullanıcıya faydalı `route_desc` açıklaması ekleyin.
