# DQ_013 — Çok az sefer

> Karar: Feed'de sefer sayısı 1 veya 2 ise işlevsel transit verisi için çok düşük kapsamlıdır.
> ⚠️ 0 trip durumunu yakalamaz.

| Alan | Değer |
|---|---|
| Grup | DQ — Veri Kalitesi |
| Önem | Orta |
| Sınıf | Quality |
| Aşama | K6 |
| Varlık | Feed |
| Kimlik alanı | - |
| Skor tabanı | 1 |
| Görünürlük | VS (`R2`, `R5`, `R9`) |
| Bloke ettiği kurallar | - |

## Tetikleme koşulu (kesin mantık)
K6 trip sayısını `records.trips.len()` ile alır.

Trip sayısı `> 0` ve `< 3` ise DQ_013 üretilir. Sıfır trip bu kuralın konusu değildir.

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** 0 trip durumunu yakalamaz.
- **Yanlış pozitif:** Demo feed'lerinde az sefer bilinçli olabilir; yayın verisi için kapsam yetersizdir.
