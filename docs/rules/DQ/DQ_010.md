# DQ_010 — Acente hiçbir hatta kullanılmıyor

> Karar: `agency.txt` içinde tanımlı bir agency hiçbir route tarafından referanslanmıyorsa kullanılmayan kayıt olabilir.
> ⚠️ `agency_id` boş agency kayıtları bu kuralda atlanır.

| Alan | Değer |
|---|---|
| Grup | DQ — Veri Kalitesi |
| Önem | Bilgi |
| Sınıf | Quality |
| Aşama | K6 |
| Varlık | Feed |
| Kimlik alanı | - |
| Skor tabanı | 1 |
| Görünürlük | VS (`R2`, `R5`, `R9`) |
| Bloke ettiği kurallar | - |

## Tetikleme koşulu (kesin mantık)
K6 `routes.txt` içindeki dolu `agency_id` değerlerini set olarak toplar.

Sonra `agency.txt` kayıtlarını gezer. `agency_id` yoksa atlar. Agency id route setinde yoksa DQ_010 üretilir.

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** `agency_id` boş agency kayıtları bu kuralda atlanır.
- **Yanlış pozitif:** Çoklu agency feed'inde bazı agency kayıtları gelecek yayın için tutuluyor olabilir; kalite uyarısıdır.

## Mesaj & çözüm önerisi
### R9 Kural Mesajı
- **Kural mesajı:** Acente hiçbir hatta kullanılmıyor
- **Çözüm önerisi:** Kullanılmayan agency kaydını kaldırın veya route'larda `agency_id` ile referanslayın.

### R2 mesajı/mesajları
- **Ayrıntılı bulgu mesajı:** *"'<agency_label>' işleticisi hiçbir hatta kullanılmıyor."*
- **Ayrıntılı çözüm:** *"Kullanılmayan agency kaydını kaldırın ya da routes.txt'de agency_id atayın."*
