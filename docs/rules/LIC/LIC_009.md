# LIC_009 — Özel lisans URL geçersiz

> **Karar:** Dolu custom_license_url geçerli http/https URL değilse bildirim üretilir.

| Alan | Değer |
|---|---|
| Grup | LIC — Licensing |
| Önem | Kritik |
| Sınıf | Spec |

| Varlık | Row |

| Skor tabanı | 1 |
| Görünürlük | VS_K (`R1`, `R2`, `R5`, `R9`) |
| Bloke ettiği kurallar | - |

## Tetikleme koşulu

Dolu custom_license_url geçerli http/https URL değilse. `licenses.txt` varsa satırlar dosya sırasıyla işlenir.

## Yanlış pozitif / negatif

Boş URL hücresi bu biçim kuralını tetiklemez. Doluyken ham değer looks_like_url ile kontrol edilir ve http/https şeması gerekir.

## Karışan komşular

LIC_001 lisans kimliği ile URL alanlarının birlikte boş olmasını ölçer.

## Mesaj & çözüm önerisi

### R9 Kural Mesajı

- **Kural mesajı:** Özel lisans URL geçersiz
- **Çözüm önerisi:** Geçerli bir http veya https URL girin.

## Ölçülen alan / değer

`licenses.txt` içindeki ilgili satır ve lisans alanları ölçülür. Bulgu dosya ve satır numarasını taşır.

## Kod değiştirirken minimum test matrisi

- Koşulu sağlayan satırda `LIC_009` üretilir.
- Geçerli feed geneli lisans satırında `LIC_009` üretilmez.
