# LIC_001 — Lisans değeri eksik

> **Karar:** İki lisans alanı boşsa bildirim üretilir.

| Alan | Değer |
|---|---|
| Grup | LIC — Licensing |
| Önem | Kritik |
| Sınıf | Spec |
| Aşama | K1 |
| Varlık | Row |
| Kimlik alanı | - |
| Skor tabanı | 1 |
| Görünürlük | VS_K (`R1`, `R2`, `R5`, `R9`) |
| Bloke ettiği kurallar | - |

## Tetikleme koşulu

İki lisans alanı boşsa. `licenses.txt` varsa satırlar dosya sırasıyla işlenir.

## Yanlış pozitif / negatif

Boş veya yalnız boşluk içeren iki lisans hücresi bulunur. Tümüyle boş CSV satırı K1 tarafından ARC_018 olarak ele alınır.

## Karışan komşular

LIC_002 iki lisans alanının birlikte dolu olmasını ölçer.

## Mesaj & çözüm önerisi

### R9 Kural Mesajı

- **Kural mesajı:** Lisans değeri eksik
- **Çözüm önerisi:** SPDX kimliği veya özel lisans URL alanlarından birini doldurun.

## Ölçülen alan / değer

`licenses.txt` içindeki ilgili satır ve lisans alanları ölçülür. Bulgu dosya ve satır numarasını taşır.

## Kod değiştirirken minimum test matrisi

- Koşulu sağlayan satırda `LIC_001` üretilir.
- Geçerli feed geneli lisans satırında `LIC_001` üretilmez.
