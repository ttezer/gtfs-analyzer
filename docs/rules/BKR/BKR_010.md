# BKR_010 — prior_notice_start_day belirtilmişse prior_notice_start_time zorunlu

> **Karar:** `prior_notice_start_day` dolu olduğu halde `prior_notice_start_time` boşsa BKR_010 üretilir. Erken rezervasyon başlangıç günü, başlangıç saati olmadan eksik kalır. **Düzeltme:** Erken rezervasyon penceresi başlangıç saatini `HH:MM:SS` biçiminde girin.
> ⚠️ Bu kural `booking_type` değerinden bağımsız alan ilişkisini kontrol eder; `prior_notice_start_day` yanlış bağlamda kullanılmışsa başka BKR kuralları da üretilebilir.
