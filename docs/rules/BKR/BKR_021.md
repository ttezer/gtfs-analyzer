# BKR_021 — info_url geçersiz

> **Karar:** `booking_rules.txt.info_url` dolduğunda geçerli bir `http/https` URL olmalıdır. DÜŞÜK, Spec.
> 📌 Bu alan `k1_parse::known_columns` listesinde vardı — yani "bilinmeyen sütun" uyarısı **almıyordu** — ama hiçbir denetim aşaması okumuyordu (issue #60).

## Tetikleme koşulu (kesin mantık)
```text
K2: info_url dolu
VE looks_like_url(info_url) false
→ BKR_021
```

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** Boş `info_url` hata değildir (alan Optional).
- **Yanlış pozitif:** URL biçimsel olarak doğrulanır; gerçekten açılıp açılmadığı kontrol edilmez.

## Neden DÜŞÜK (booking_url'in ORTA'sından farklı)
`info_url` yalnız açıklayıcı bir bilgi sayfasıdır; bozuk olması hizmetin rezerve edilmesini
engellemez. Eylem yolu `booking_url`'dir (BKR_020) ve o ORTA'dır.

## Mesaj & çözüm önerisi
### R9 Kural Mesajı
- **Kural mesajı:** info_url geçersiz
- **Çözüm önerisi:** `info_url` için geçerli bir `http/https` URL kullanın.

### R2 mesajı/mesajları
- **Ayrıntılı bulgu mesajı:** *"info_url geçerli bir URL değil."*
- **Ayrıntılı çözüm:** *"info_url için geçerli bir http/https URL'si kullanın."*

## Ölçülen alan / değer
- **Dosya/alan:** `booking_rules.txt` → `info_url`
- **Gözlenen değer:** geçersiz URL metni
- **Beklenen değer:** `http://` veya `https://` ile başlayan geçerli URL

## Kod değiştirirken minimum test matrisi
- `info_url=https://example.com/info` → BKR_021 çıkmamalı.
- `info_url=notaurl` → BKR_021 çıkmalı.
- `info_url` boş → BKR_021 çıkmamalı.
- `booking_url` bozuk → BKR_021 çıkmamalı (o BKR_020).
