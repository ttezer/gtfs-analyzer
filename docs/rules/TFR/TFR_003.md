# TFR_003 — start_time veya end_time format hatası

> **Karar:** `timeframes.txt::start_time` veya `end_time` geçerli `HH:MM:SS` biçiminde değil. YÜKSEK, Spec. **Düzeltme:** `HH:MM:SS` formatında geçerli bir değer girin.
