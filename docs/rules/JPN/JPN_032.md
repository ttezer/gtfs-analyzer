# JPN_032 — GTFS-JP V3: agency_id Corporate Number biçiminde değil

> **Karar:** Açık GTFS-JP V3 profilinde `agency_id`, işletmecinin 13 haneli Japonya Corporate Number gövdesini taşımalıdır. `_` sonrasında boş olmayan dal kimliği kullanılabilir. Bu kural kurum eşleşmesini dışarıdan doğrulamaz.

| Alan | Değer |
|---|---|
| Grup | JPN — GTFS-JP |
| Önem | Orta |
| Sınıf | Interop |
| Otorite kaynağı | REGIONAL_PROFILE |
| Aşama | K4 |
| Varlık | Entity |
| Kimlik alanı | `agency_id` |
| Skor tabanı | 1 |
| Görünürlük | VI (`R2`, `R5`, `R8`, `R9`) |
| Bloke ettiği kurallar | - |

## Tetikleme koşulu (kesin mantık)

1. Bağımsız GTFS-JP detection gate'i açık olmalıdır.
2. Profil açıkça **V3** olmalıdır. Auto ve V4'te bu kural sessizdir.
3. `agency.txt` satırındaki boş olmayan `agency_id` değeri tam 13 ASCII rakamdan oluşmalı veya bu gövdeyi `_` ile ayrılmış boş olmayan bir dal kimliği izlemelidir.

Eksik/boş değerleri JPN_011 sahiplenir. Suffix için MLIT'nin tanımlamadığı karakter, uzunluk veya rakam kısıtları icat edilmez; gerçek Corporate Number kurum eşleşmesi de kapsam dışıdır.

## Yanlış pozitif / negatif (asıl tasarım riski)

- Japonya dışı veya sentetik bir kimlik 13 rakamlı olsa bile biçim bakımından geçerli sayılır; bu kural gerçek kurumu doğrulamaz.
- V4'te Corporate Number öneri/arbitrary ID ayrımı bulunduğu için kural uygulanmaz.
- Auto sürüm tahmini yapmaz; kural uygulanmaz.

## Karışan komşular (ayrım)

| Kural | Ne yakalar | Eksen |
|---|---|---|
| **JPN_011** | GTFS-JP'de boş agency_id | zorunlu alan |
| **AGN_010** | Yinelenen agency_id | GTFS genel tekillik |
| **JPN_032** | V3'te dolu agency_id'nin 13 haneli Corporate Number gövdesine uymaması | profil biçimi |

## Mesaj & çözüm önerisi

### R9 Kural Mesajı

- **Kural mesajı:** GTFS-JP V3: agency_id Corporate Number biçiminde değil
- **Çözüm önerisi:** agency_id'yi 13 haneli ASCII Corporate Number olarak yazın; gerekiyorsa `_` ile boş olmayan dal kimliği ekleyin.

## Ölçülen alan / değer

`agency.txt:agency_id`, işletici satırı, ham değer ve beklenen biçim.

## Kod değiştirirken minimum test matrisi

- 13 ASCII rakam: sessiz.
- 13 rakam + `_` + boş olmayan suffix: sessiz.
- Kısa/uzun, ASCII dışı veya boş suffix: JPN_032.
- Boş agency_id: yalnız JPN_011.
- V4, Auto veya detection gate kapalı: JPN_032 sessiz.
