# TRP_028 — Bazı seferler tekerlekli sandalye erişilebilirliği işaretlememiş

> **Karar:** Seferlerin bir kısmında `wheelchair_accessible` eksik (=0), bir kısmında dolu; kısmi erişilebilirlik kapsamı. ORTA, Quality. **Düzeltme:** Tüm seferlerin `wheelchair_accessible` alanını doldurun (1=erişilebilir, 2=erişilemez).
> ⚠️ Feed seviyesinde tek özet; **bazıları** eksik (`0 < unset < total`) durumudur. Hiçbiri doldurmamışsa TRP_029, hepsi doldurmuşsa notice yok.

## Tetikleme koşulu (kesin mantık)
`k6_analytics::check_operational_analytics()` içinde:
```
unset = wheelchair_accessible (None→0 sayılır) == 0 olan sefer sayısı
unset != total VE unset > 0
→ TRP_028 (feed-level notice)
```
- Kapsam birimi: feed.

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** Tüm seferler eksikse TRP_029 (bu kural değil) çıkar.
- **Yanlış pozitif:** Erişilebilirlik bazı seferler için gerçekten bilinmiyorsa kapsam sinyalidir.
