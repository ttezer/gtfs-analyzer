# TRP_021 — Bisiklet izni (bikes_allowed) belirtilmemiş

> **Karar:** Seferlerde `bikes_allowed` alanı boş bırakılmış; bisiklet taşıma bilgisi yok. BİLGİ, Quality. **Düzeltme:** `bikes_allowed` değerini 0 (bilgi yok), 1 (izinli) veya 2 (izinsiz) olarak ayarlayın.
> ⚠️ Feed genelinde hiç doldurulmamışsa **tek özet** notice; bazı seferler doldurmuşsa eksik olanlar **per-trip** raporlanır (tutarsızlık).

## Tetikleme koşulu (kesin mantık)
`k2::trips::validate()` içinde:
```
bikes_allowed boş seferler toplanır
eğer hiçbir seferde set edilmemişse → tek feed-level özet notice
eğer bazıları set etmişse → eksik olanlar için per-trip notice
→ TRP_021
```
- Kapsam birimi: trip (entity) veya feed özeti.

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** Geçersiz (>2) değer TRP_007 kapsamındadır, eksiklik değildir.
- **Yanlış pozitif:** Bisiklet politikası bilinmiyorsa boş bırakmak meşrudur; bilgi notudur.
