# TRP_024 — Block içinde tutarsız rota tipi

> **Karar:** Aynı `block_id`'deki seferler farklı `route_type` değerlerine ait; tek araç bloğu içinde tür değişimi olağandışı. DÜŞÜK, Interop. **Düzeltme:** Aynı block içindeki tüm seferlerin aynı rota tipine sahip olmasını sağlayın.
> ⚠️ İlk görülen route_type referans alınır; bloktaki sonraki farklı türler tetikler.

## Tetikleme koşulu (kesin mantık)
`k6_analytics::check_operational_analytics()` içinde:
```
block_id → ilk görülen (route_type, trip_id) saklanır
aynı blokta route_type farklı bir sefer görülürse
→ TRP_024 (trip bazlı notice)
```
- Kapsam birimi: trip (entity).

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** route_type'ı tanımsız hatlara ait seferler değerlendirilmez.
- **Yanlış pozitif:** Çok modlu (ör. otobüs+vapur aktarmalı) bloklar nadiren meşru olabilir.
