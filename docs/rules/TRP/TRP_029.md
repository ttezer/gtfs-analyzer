# TRP_029 — Hiçbir sefer tekerlekli sandalye erişilebilirliği bildirmemiş

> **Karar:** Feed'deki seferlerin **hiçbirinde** `wheelchair_accessible` bilgisi yok (hepsi 0/boş). BİLGİ, Quality. **Düzeltme:** Tekerlekli sandalye erişilebilirliğini `wheelchair_accessible` alanıyla bildirin (1=erişilebilir, 2=erişilemez).
> ⚠️ Feed seviyesinde tek özet; **tüm** seferler eksikse (`unset == total`) tetiklenir. Kısmi eksiklik TRP_028 kapsamındadır.

## Tetikleme koşulu (kesin mantık)
`k6_analytics::check_operational_analytics()` içinde:
```
unset = wheelchair_accessible (None→0) == 0 olan sefer sayısı
unset == total (hepsi eksik) VE total > 0
→ TRP_029 (feed-level notice)
```
- Kapsam birimi: feed.

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** En az bir sefer doldurmuşsa TRP_028 (bu kural değil) çıkar.
- **Yanlış pozitif:** Erişilebilirlik verisi hiç toplanmamışsa bilgi notudur.
