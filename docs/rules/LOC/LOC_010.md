# LOC_010 — Geometry 'coordinates' eksik veya dizi değil — bölge geometrisi çözümlenemez

> **Karar:** `locations.geojson` içinde bir Feature'ın zorunlu `coordinates` üyesi eksik (ya da beklenen tipte değil). KRITIK, Spec. **Düzeltme:** Geometriye geçerli bir 'coordinates' dizisi ekleyin.
> ⚠️ Spec alan tablosu: `coordinates` — Array — **Required**. Eksikse bölge hiç çözümlenemez → KRİTİK. 2026-08-01'e kadar bu üye hiç denetlenmiyordu: eksikliğinde kod sessizce atlıyor, dosya "doğrulandı" görünüyordu.

## Tetikleme koşulu (kesin mantık)


## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** `locations.geojson` hiç ayrıştırılamıyorsa (LOC_001) feature döngüsüne girilmez.
- **Yanlış pozitif:** Yok — spec bu üyeyi Required işaretler; varlık kontrolü yoruma açık değildir.
