# LOC_006 — Polygon yaklaşık kapsamı 500km²'yi aşıyor

> **Karar:** `locations.geojson` içindeki bir polygonun koordinatlarından hesaplanan yaklaşık bounding-box alanı `500km²` üstündeyse Flex bölgesi gerçekçi olmayacak kadar geniş kabul edilir. ORTA, kalite sorunu. **Düzeltme:** Bölge geometrisini gerçek hizmet alanını kapsayacak şekilde küçültün veya daha küçük bölgelere ayırın.
> ⚠️ Bu gerçek polygon alanı değil bounding-box tahminidir; ince uzun veya dağınık geometri olduğundan yüksek çıkabilir.

## Tetikleme koşulu (kesin mantık)
`k1_parse::check_polygon_rings()` içinde:
```
Polygon/MultiPolygon ring koordinatlarından tüm lat/lon değerleri toplanır
VE en az 3 lat değeri vardır
VE bbox_km2 = ((max_lat-min_lat)*111) * ((max_lon-min_lon)*111*cos(avg_lat)) > 500.0
→ LOC_006
```
- Gözlenen değer yaklaşık `"{bbox_km2:.0}km²"` olarak rapora gider.
- Hesap gerçek geodezik alan değil, bounding-box alan tahminidir.
- Aynı ring kontrolü LOC_004 kapanış hatasını da üretebilir.

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış pozitif:** İnce uzun veya çok parçalı ama gerçek hizmet alanı küçük bir geometri bounding-box nedeniyle 500km² üstüne çıkabilir.
- **Yanlış negatif:** Büyük ama bbox genişliği/düşeyliği eşiği aşmayacak şekilde kurgulanmış veya koordinatları eksik parse edilen geometri kaçabilir.

- **Kural mesajı:** Polygon yaklaşık kapsamı 500km²'yi aşıyor — gerçekçi olmayan Flex bölge (bounding-box tahmini)
- **Çözüm önerisi:** Flex hizmet bölgesini gerçek operasyon alanını gösterecek şekilde küçültün veya birden fazla daha küçük bölgeye ayırın.

- **Çözüm önerisi:** *"Bölge geometrisini gerçek hizmet alanını kapsayacak şekilde küçültün."*

## Ölçülen alan / değer
- **Dosya/alan:** `locations.geojson` → `features[*].geometry.coordinates`
- **Gözlenen değer:** Yaklaşık bbox alanı `> 500km²`.
- **Beklenen değer:** Yaklaşık bbox alanı `<= 500km²` veya operasyonel olarak savunulabilir daha dar hizmet bölgesi.

## Kod değiştirirken minimum test matrisi
- Bbox alanı 501km² olan polygon → LOC_006 çıkmalı.
- Bbox alanı 500km² veya altı → LOC_006 çıkmamalı.
- MultiPolygon koordinatları birlikte geniş bbox oluşturuyor → LOC_006 çıkmalı.
- Kapalı ama çok büyük polygon → LOC_006 çıkmalı, LOC_004 çıkmamalı.
- Koordinat sayısı 3'ten az → LOC_006 çıkmamalı.
