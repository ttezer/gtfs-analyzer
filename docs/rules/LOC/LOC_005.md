# LOC_005 — FeatureCollection boş

> **Karar:** `locations.geojson` geçerli `FeatureCollection` olsa bile `features` dizisi boşsa feed hiçbir Flex lokasyon bölgesi tanımlamaz. DÜŞÜK, kalite sorunu. **Düzeltme:** GTFS Flex kullanılacaksa en az bir `Polygon` veya `MultiPolygon` feature ekleyin; kullanılmayacaksa dosyanın gerekliliğini yeniden değerlendirin.
> ⚠️ LOC_005 sadece `features: []` durumunu yakalar; `features` alanının tamamen eksik olması mevcut kodda notice üretmeden geçebilir.

## Tetikleme koşulu (kesin mantık)
`k1_parse::validate_locations_geojson()` içinde:
```
root.type == "FeatureCollection"
VE features alanı array olarak var
VE features.is_empty()
→ LOC_005
```
- LOC_005 üretildikten sonra fonksiyon erken döner.
- Boş koleksiyonda feature düzeyi kontroller doğal olarak çalışmaz.
- `features` array değilse veya yoksa mevcut kod LOC_005 üretmez.

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** `features` alanı eksik veya array değilse bu kural çıkmaz.
- **Yanlış pozitif:** Dosya bilerek boş şablon olarak bırakılmış olabilir; yayın feed'i açısından yine de kullanışlı Flex lokasyon tanımı yoktur.
