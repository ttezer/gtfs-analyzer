# LOC_009 — Feature 'properties' nesnesi eksik

> **Karar:** `locations.geojson` içinde bir Feature'ın zorunlu `properties` üyesi eksik (ya da beklenen tipte değil). ORTA, Spec. **Düzeltme:** Her feature'a bir 'properties' nesnesi ekleyin (boş nesne de geçerlidir).
> ⚠️ Spec alan tablosu: `properties` — Object — **Required**. Boş nesne GEÇERLİDİR (`stop_name`/`stop_desc` opsiyoneldir). 2026-08-01'e kadar bu üye hiç denetlenmiyordu: eksikliğinde kod sessizce atlıyor, dosya "doğrulandı" görünüyordu.

## Tetikleme koşulu (kesin mantık)
`k1_parse::validate_locations_geojson()` feature döngüsünde:
```
feature'ın 'properties' üyesi yok VEYA beklenen tipte değil
→ LOC_009 (feature başına bir notice; satır alanı feature sırasıdır)
```

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** `locations.geojson` hiç ayrıştırılamıyorsa (LOC_001) feature döngüsüne girilmez.
- **Yanlış pozitif:** Yok — spec bu üyeyi Required işaretler; varlık kontrolü yoruma açık değildir.
