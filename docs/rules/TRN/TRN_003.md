# TRN_003 — language geçersiz

> **Karar:** `translations.txt::language` geçerli bir IETF BCP 47 dil etiketi değil. ORTA, Spec. **Düzeltme:** Geçerli bir BCP 47 dil etiketi kullanın (ör. `tr`, `en`, `de-CH`).
> ⚠️ Satır bazlı (Row); kontrol BCP 47 biçim sezgisi (`looks_like_bcp47`) ile yapılır.

## Tetikleme koşulu (kesin mantık)
`k2::translations::validate_translations()` içinde:
```
looks_like_bcp47(language) == false
→ TRN_003 (satır bazlı notice)
```
- Kapsam birimi: satır (Row).

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** Sözdizimsel olarak geçerli ama var olmayan dil kodu (`zz`) yakalanmayabilir (biçim sezgisi semantik değil).
- **Yanlış pozitif:** Az bilinen ama geçerli BCP 47 alt etiketleri sezgiyi geçemezse hatalı raporlanabilir.
