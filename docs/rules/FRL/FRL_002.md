# FRL_002 — route_id bulunamadı

> **Karar:** `fare_rules.txt.route_id` dolu ama `routes.txt` içinde tanımlı değil. KRİTİK, spec hatası. **Düzeltme:** Geçerli bir `route_id` kullanın veya ilgili hattı `routes.txt` içine ekleyin.
> ⚠️ Bu kural yalnızca dolu `route_id` için çalışır; boş `route_id` route filtresi uygulanmadığı anlamına gelebilir.

| Alan | Değer |
|---|---|
| Grup | FRL — Fare Rules |
| Önem | Kritik |
| Sınıf | Spec |
| Aşama | K4 |
| Varlık | Row |
| Kimlik alanı | `route_id` |
| Skor tabanı | 1 |
| Görünürlük | VS_K (`R1`, `R2`, `R5`, `R9`) |
| Bloke ettiği kurallar | - |

## Tetikleme koşulu (kesin mantık)
`k4_cross_ref::check_fare_rules()` içinde:
```
fare_rules.route_id dolu
VE map.routes içinde yok
→ FRL_002
```
- Entity id `route_id` olarak verilir.
- Hedef tablo `routes.txt` kayıtlarıdır.

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** Boş `route_id` FRL_002 üretmez.
- **Yanlış pozitif:** Hattın harici sistemde var olması yetmez; GTFS feed içinde `routes.txt` kaydı bulunmalıdır.
