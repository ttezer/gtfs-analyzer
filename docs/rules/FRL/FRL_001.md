# FRL_001 — fare_id bulunamadı

> **Karar:** `fare_rules.txt.fare_id` dolu ama `fare_attributes.txt` içinde tanımlı değil. KRİTİK, spec hatası. **Düzeltme:** Geçerli bir `fare_id` kullanın veya ücret tarifesini `fare_attributes.txt` içine ekleyin.
> ⚠️ Bu Fares v1 foreign key kontrolüdür; `fare_id` boşsa bu kural çalışmaz, boşluk ayrı zorunlu alan kontrolünün konusudur.

## Tetikleme koşulu (kesin mantık)
`k4_cross_ref::check_fare_rules()` içinde:
```
fare_rules.fare_id boş değil
VE map.fare_attrs içinde yok
→ FRL_001
```
- Entity id `fare_id` değeridir.
- Hedef tablo `fare_attributes.txt` kayıtlarıdır.

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** Boş `fare_id` FRL_001 üretmez.
- **Yanlış pozitif:** Ücret başka sistemde bilinse bile feed içinde `fare_attributes.txt` kaydı yoksa referans geçersizdir.
