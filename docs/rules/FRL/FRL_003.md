# FRL_003 — origin_id geçersiz

> **Karar:** `fare_rules.txt.origin_id` dolu ama `stops.txt.zone_id` kümesinde yok. KRİTİK, spec hatası. **Düzeltme:** Geçerli bir `zone_id` kullanın.
> ⚠️ Bu alan adı `origin_id` olsa da kontrol edilen hedef `zone_id` değeridir; stop id ile karıştırılmamalıdır.
> ℹ️ **DISTINCT `origin_id` başına tek notice** — aynı tanımsız zone binlerce satırda geçse de bir kez raporlanır; mesaj kaç satırda kullanıldığını söyler. (2026-07-17 patlama fix'i, bkz. FRL_001.)

## Tetikleme koşulu (kesin mantık)
`k4_cross_ref::check_fare_rules()` içinde:
```
fare_rules.origin_id dolu
VE map.zone_ids içinde yok
→ FRL_003
```
- `map.zone_ids`, `stops.txt.zone_id` değerlerinden kurulur.
- Entity id `fare_id` değeridir.

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** Boş `origin_id` FRL_003 üretmez.
- **Yanlış pozitif:** `origin_id` stop id gibi verilmişse hata doğrudur; beklenen değer zone id'dir.
