# FMD_002 — fare_media_type eksik veya geçersiz

> **Karar:** `fare_media_type` boş, sayısal değil veya `0..4` aralığı dışında. KRİTİK, spec hatası. **Düzeltme:** Geçerli bir `fare_media_type` enum değeri girin.
> ⚠️ Mevcut kod sayısal enum aralığını doğrular; çözüm metnindeki tip adları güncel GTFS spec adlarıyla birebir aynı değildir. Güncel spec anlamları aşağıdaki referans bölümünde esas alınmalıdır.

## Tetikleme koşulu (kesin mantık)
K2 `parse_u32(row, "fare_media_type")` ile değeri okur. Değer boşsa, parse edilemiyorsa veya `0`, `1`, `2`, `3`, `4` dışında kalıyorsa FMD_002 notice'ı üretir.

Kaynak: [`crates/pipeline/src/k2/fare_media.rs`](../../../crates/pipeline/src/k2/fare_media.rs)

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** Üçüncü taraf spec dışı bir medya tipi metinsel olarak açıklansa bile enum `0..4` dışında ise kabul edilmez.
- **Yanlış pozitif:** Kod enum aralığını doğru yakalar; ancak R2 çözüm metnindeki tip adları güncel GTFS spec adlarıyla birebir örtüşmediği için insan yorumunda karışıklık yaratabilir.
