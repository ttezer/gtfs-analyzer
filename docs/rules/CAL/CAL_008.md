# CAL_008 — Servis tarihi yakında sona eriyor

> **Karar:** `calendar.txt` içindeki bir servisin `end_date` değeri bugünden sonra ama `feed_expiry_warning_days` eşiği içinde. YÜKSEK, operasyonel analiz uyarısı. **Düzeltme:** Feed'i güncellemeyi planlayın.
> ⚠️ Bu kontrol yalnızca `calendar.txt.end_date` üzerinden çalışır; `calendar_dates.txt` ile gelecekte eklenmiş günleri hesaba katmaz.

## Tetikleme koşulu (kesin mantık)
`k6_analytics::check_calendar_analytics()` içinde:
```
end_date >= bugün
VE end_date bugünden sonra
VE end_date - bugün <= feed_expiry_warning_days
→ CAL_008
```
- Varsayılan eşik config tarafında `feed_expiry_warning_days` değeridir.
- `end_date < bugün` ise CAL_008 değil CAL_013 çıkar.
- `end_date == bugün` mevcut kodda CAL_008 üretmez; çünkü fark `end_jdn > today_jdn` şartına bağlıdır.

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış pozitif:** Feed kısa dönemli bilinçli yayınlanıyorsa uyarı beklenen davranıştır, hata değildir.
- **Yanlış negatif:** `calendar_dates.txt` ile daha ileri aktif günler varsa CAL_008 yine `calendar.txt.end_date` sınırına göre konuşur.
