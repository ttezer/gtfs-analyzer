# CAL_004 — end_date eksik veya geçersiz format

> **Karar:** `calendar.txt` satırında `end_date` yok veya `YYYYMMDD` servis tarihi olarak parse edilemiyor. KRİTİK, yayın engelleyici. **Düzeltme:** `end_date` alanını geçerli `YYYYMMDD` formatında doldurun.
> ⚠️ Bu kural bitiş tarihinin formatını kontrol eder; tarihin geçmişte kalması CAL_009/CAL_013, `start_date`ten önce olması CAL_005 konusudur.


- Format hatasında observed value ham alan değeridir, expected value `YYYYMMDD`.
- Geçerli parse edilen tarih CAL_005 ve daha sonraki expiry/aktif tarih kontrollerine temel olur.

- **Yanlış pozitif:** `YYYY-MM-DD` gibi insanlar için okunabilir formatlar GTFS `Date` değildir; CAL_004 doğru şekilde çıkar.
