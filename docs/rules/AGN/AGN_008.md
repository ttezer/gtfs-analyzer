# AGN_008 — agency_fare_url geçersiz

> Karar: `agency_fare_url` verilmişse geçerli URL biçiminde olmalıdır.
> ⚠️ URL'nin gerçekten açılıp açılmadığı kontrol edilmez.

## Tetikleme koşulu (kesin mantık)
K2 `agency_fare_url` değerini okur. Alan boşsa kural çalışmaz; çünkü ücret URL'si opsiyoneldir.

Alan doluysa `looks_like_url` kontrolünden geçmelidir. Geçmezse AGN_008 üretilir.

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** URL'nin gerçekten açılıp açılmadığı kontrol edilmez.
- **Yanlış pozitif:** Protokolsüz değerler (`example.com/fares`) URL gibi görünse de geçerli kabul edilmeyebilir.
