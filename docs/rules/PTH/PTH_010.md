# PTH_010 — min_width geçersiz

> **Karar:** `pathways.txt.min_width` dolu olduğu halde pozitif sayısal değer değilse geçit genişliği güvenilir yorumlanamaz. DÜŞÜK, spec hatası. **Düzeltme:** `min_width` alanını metre cinsinden pozitif sayısal değere ayarlayın.

## Tetikleme koşulu (kesin mantık)
`k2::pathways::validate_pathways()` içinde:
```
min_width parse_f64 ile okunur
VE (
  parse_f64 hata verir
  VEYA min_width <= 0
)
→ PTH_010
```
- Alan yoksa veya boşsa `Ok(None)` kabul edilir.
- `0` geçersizdir; pozitif değer gerekir.
- Gözlenen/beklenen değer helper tarafından üretilir.

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** Boş `min_width` bu kuralı tetiklemez.
- **Yanlış pozitif:** Yerel ondalık virgül (`1,2`) sayısal parse hatasına düşer.
