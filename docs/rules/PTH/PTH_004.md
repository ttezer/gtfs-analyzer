# PTH_004 — pathway_mode eksik veya geçersiz

> **Karar:** `pathways.txt.pathway_mode` değeri `1`-`7` enum aralığında değilse geçit tipi yorumlanamaz. KRİTİK, spec hatası. **Düzeltme:** `pathway_mode` alanını GTFS'in izin verdiği değerlerden biriyle doldurun.
