# PTH_015 — Geçit hedefi erişilemeyen durakta

> **Karar:** `pathways.txt.length` ve `traversal_time` değerlerinden türetilen hız `3.0 m/s` üstündeyse geçit süresi/uzunluğu tutarsız kabul edilir. ORTA, analitik uyarı. **Düzeltme:** `length` ve `traversal_time` değerlerini gerçekçi olacak şekilde güncelleyin.
> ⚠️ Registry başlığı hedef erişilemeyen durak dese de mevcut kodun gerçek mantığı length/traversal_time hız tutarlılığıdır; kart kod davranışını esas alır.

## Tetikleme koşulu (kesin mantık)
`k6_analytics::check_pathway_analytics()` içinde:
```
pathway_id boş değil
VE length Some ve > 0
VE traversal_time Some ve > 0
VE speed = length / traversal_time > 3.0
→ PTH_015
```
- Eşik sabit `3.0 m/s`.
- Notice `traversal_time|length` alanını işaret eder.
- K2 parse/range sorunları PTH_006/PTH_007 kapsamındadır.

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** `length` veya `traversal_time` boşsa hız tutarlılığı kontrol edilmez.
- **Yanlış pozitif:** Çok hızlı yürüyüş/koşu gibi istisnai durumlar olabilir; pathway traversal zamanı yolcu ortalamasına göre gerçekçi olmalıdır.

- **Ayrıntılı bulgu mesajı:** *"pathway_id '{pathway_id}' length={length}m ve traversal_time={tt}s'den türetilen hız {speed} m/s — makul sınır 3 m/s."*

## Ölçülen alan / değer
- **Dosya/alan:** `pathways.txt` → `length`, `traversal_time`
- **Gözlenen değer:** `{speed} m/s ({length}m / {tt}s)`
- **Beklenen değer:** `≤ 3.0 m/s`

## Kod değiştirirken minimum test matrisi
- `length=300`, `traversal_time=50` → PTH_015 çıkmalı.
- `length=100`, `traversal_time=60` → PTH_015 çıkmamalı.
- `length` boş → PTH_015 çıkmamalı.
- `traversal_time` boş → PTH_015 çıkmamalı.
- PTH_006/PTH_007 parse hataları PTH_015 hesaplamasını maskelemeli.
