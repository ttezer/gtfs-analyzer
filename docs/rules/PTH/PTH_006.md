# PTH_006 — length geçersiz

> **Karar:** `pathways.txt.length` dolu olduğu halde sayısal değilse veya negatifse geçit uzunluğu güvenilir ölçülemez. ORTA, spec hatası. **Düzeltme:** `length` alanını metre cinsinden sıfır veya pozitif sayısal değere ayarlayın.

## Tetikleme koşulu (kesin mantık)
`k2::pathways::validate_pathways()` içinde:
```
length parse_f64 ile okunur
VE (
  parse_f64 hata verir
  VEYA length < 0
)
→ PTH_006
```
- Alan yoksa veya boşsa `Ok(None)` kabul edilir.
- `0` değeri geçerlidir.
- Makul hız/uzunluk tutarlılığı PTH_015 kapsamındadır.

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** Boş length değeri bu kuralı tetiklemez.
- **Yanlış pozitif:** Yerel ondalık virgül kullanımı (`1,5`) sayısal parse hatasına düşer.
