# FAR_003 — currency_type eksik

> **Karar:** `currency_type` alanı üç harfli büyük harf ISO 4217 para birimi kodu değilse FAR_003 üretilir. Boş değer de bu kontrole takılır. **Düzeltme:** 3 harfli büyük harf ISO 4217 para birimi kodu kullanın.
> ⚠️ Bu kural yalnızca biçimsel ISO 4217 görünümünü denetler: uzunluk 3 ve ASCII büyük harf. Kod, girilen üç harfli kodun aktif ISO listesinde gerçekten var olup olmadığını ayrıca doğrulamaz.

## Tetikleme koşulu (kesin mantık)
`currency_type.len() != 3` ise veya karakterlerin tamamı ASCII büyük harf değilse notice üretilir.
