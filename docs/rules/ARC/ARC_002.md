# ARC_002 — Dosya UTF-8 ile okunamıyor

> Karar: Kök dizindeki GTFS `.txt` dosyaları UTF-8 olarak okunabilmelidir; zorunlu dosyada UTF-8 hatası fatal kabul edilir.
> ⚠️ UTF-8 geçerli ama içerik semantik olarak bozuksa bu kural çalışmaz.

| Alan | Değer |
|---|---|
| Grup | ARC — Arşiv / Dosya Seviyesi |
| Önem | Kritik |
| Sınıf | Spec |
| Aşama | K1 |
| Varlık | File |
| Kimlik alanı | - |
| Skor tabanı | 1 |
| Görünürlük | VS_K (`R1`, `R2`, `R5`, `R9`) |
| Bloke ettiği kurallar | `ARC_010`, `AGN_003`, `AGN_009`, `RTS_009`, `FIN_008`, `ATR_010`, `STP_022`, `DQ_016` |

## Tetikleme koşulu (kesin mantık)
K1 dosya baytlarını okuduktan sonra `std::str::from_utf8(bytes)` ile UTF-8 doğrulaması yapar. Hata varsa ARC_002 üretilir.

Dosya zorunluysa parser `FatalError::Utf8Critical` ile döner. İsteğe bağlı dosyada ise kayıplı dönüşüm uygulanır ve ARC_003 de üretilir.

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** UTF-8 geçerli ama içerik semantik olarak bozuksa bu kural çalışmaz.
- **Yanlış pozitif:** Yerel encoding ile kaydedilmiş dosya insan gözüyle okunabilir olabilir ama GTFS parser için UTF-8 değildir.
