# ARC_021 — Alanda yazdırılamaz veya sorunlu karakter

> Karar: Alan değerlerinde kontrol karakteri, DEL, Unicode surrogate, private-use veya özel sorunlu aralık karakterleri bulunmamalıdır.
> ⚠️ Kod yorumu geçerli Unicode metni muaf tutar; harf/rakam kabul edilen Unicode karakterler bu kuralın hedefi değildir.

| Alan | Değer |
|---|---|
| Grup | ARC — Arşiv / Dosya Seviyesi |
| Önem | Düşük |
| Sınıf | Quality |
| Aşama | K1/K2 |
| Varlık | File |
| Kimlik alanı | - |
| Skor tabanı | 1 |
| Görünürlük | VS (`R2`, `R5`, `R9`) |
| Bloke ettiği kurallar | - |

## Tetikleme koşulu (kesin mantık)
K1 her dosyada veri alanlarını gezer ve dosya başına ilk sorunlu karakterde ARC_021 üretir. `stop_times.txt` streaming yolunda aynı kontrol K2 içinde yapılır.

Sorunlu sayılan karakterler: tab dışındaki `U+0000..U+001F` kontrol karakterleri, `U+007F`, surrogate aralığı, private-use aralığı ve `U+FFF0..U+FFFF`.

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** Dosyada birden fazla sorunlu karakter varsa yalnız ilk notice üretildiği için diğerleri raporda görünmez.
- **Yanlış pozitif:** Mesaj metni "ASCII dışı" dese de kod alfanümerik/boşluk Unicode karakterleri atlar; gerçek tetikleyici sorunlu karakter sınıfıdır.

## Mesaj & çözüm önerisi
### R9 Kural Mesajı
- **Kural mesajı:** Alanda yazdırılamaz veya sorunlu karakter
- **Çözüm önerisi:** Yazdırılamaz/kontrol karakterlerini alan değerlerinden temizleyin.

### R2 mesajı/mesajları
- **Ayrıntılı bulgu mesajı:** *"'<file>' dosyasında yazdırılamaz veya sorunlu karakter içeren değer var (U+<codepoint>)."*
- **Ayrıntılı çözüm:** *"Alan değerlerindeki kontrol/yazdırılamaz karakterleri kaldırın; geçerli Unicode harfler (ü, ö, 漢字 vb.) sorun değildir."*
- **Not (2026-07-24):** Eski mesaj "ASCII dışı" diyerek yaptığından fazlasını iddia ediyordu; kural geçerli Unicode harfleri bilerek muaf tutar (kod: `arc021_bad_char`), yalnız kontrol/DEL/surrogate/private-use işaretler. Metin kod davranışıyla hizalandı.

## Ölçülen alan / değer
- `file`: ilgili `.txt`
- `field`: -
- `line`: sorunlu karakter bulunan satır
- `observed`: `U+<codepoint>`

## Kod değiştirirken minimum test matrisi
| Senaryo | Beklenen |
|---|---|

| NUL karakteri içeren değer | `ARC_021` |
| aynı dosyada birden çok sorunlu karakter | dosya başına ilk `ARC_021` |
