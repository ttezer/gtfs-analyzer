# ARC_023 — ZIP içinde nested ZIP dosyası

> Karar: GTFS ZIP arşivi içinde başka bir `.zip` dosyası bulunması proje-özel arşiv kalitesi sorunudur.
> ⚠️ Bu kural `.zip` uzantılı girdileri **kök ve alt dizin fark etmeksizin** yakalar; farklı sıkıştırma uzantıları (`.gz`, `.7z`, `.tar`) bu kontrolün kapsamı değildir.

| Alan | Değer |
|---|---|
| Grup | ARC — Arşiv / Dosya Seviyesi |
| Önem | Orta |
| Sınıf | Quality |
| Otorite kaynağı | PROJECT_QUALITY |
| Aşama | K1 |
| Varlık | File |
| Kimlik alanı | - |
| Skor tabanı | 2 |
| Görünürlük | VS (`R2`, `R5`, `R9`) |
| Bloke ettiği kurallar | - |

## Tetikleme koşulu (kesin mantık)
K1 ZIP entry adını okur. Entry adı `.zip` ile bitiyorsa ARC_023 üretir; dosya işlenmeden atlanır. Bulgu, girdinin arşiv içindeki **tam yolunu** taşır.

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** `.gz`/`.7z`/`.tar` gibi farklı sıkıştırma uzantıları bu kuralda yakalanmaz. Uzantısı `.zip` ile bitmeyen bir **klasör** adı da (ör. `google_transit_Working.zip/`) nested arşiv değildir, bu kural onu görmez.
- **Ölçüm (13. korpus koşumu, 2026-08-31):** Kural eskiden yalnız kök dizini görüyordu. Beş feed — `tdg-83019` · `tld-768_1` · `mdb-3340` · `mdb-657` · `tld-752` — bütün GTFS'ini alt dizindeki nested ZIP'te taşıyor; o feed'lerde tek çıktı `ARC_004`+`ARC_008` ("zorunlu dosya eksik") oluyor, **sebebi hiçbir bulguda görünmüyordu**. Kapsam alt dizini de içerecek şekilde genişletildi: ateşleyen feed 7 → 12.
- **Yanlış pozitif:** Yardımcı ZIP bilinçli konmuş olsa bile GTFS parserlar nested ZIP içeriğini standart feed dosyası olarak işlemez.
