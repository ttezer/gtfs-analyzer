# ARC_023 — ZIP içinde nested ZIP dosyası

> Karar: GTFS ZIP arşivi içinde kök dizinde başka bir `.zip` dosyası bulunmamalıdır.
> ⚠️ Bu kural yalnızca kök dizindeki `.zip` girişlerini yakalar; alt dizindeki veya farklı uzantılı sıkıştırılmış dosyalar bu kontrolün kesin kapsamı değildir.

| Alan | Değer |
|---|---|
| Grup | ARC — Arşiv / Dosya Seviyesi |
| Önem | Orta |
| Sınıf | Spec |
| Aşama | K1 |
| Varlık | File |
| Kimlik alanı | - |
| Skor tabanı | 2 |
| Görünürlük | VS (`R2`, `R5`, `R9`) |
| Bloke ettiği kurallar | - |

## Tetikleme koşulu (kesin mantık)
K1 ZIP entry adını okur. Entry adı `.zip` ile bitiyorsa ve ad içinde `/` veya `\` yoksa ARC_023 üretir; dosya işlenmeden atlanır.

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** Alt dizindeki nested ZIP veya farklı sıkıştırma uzantıları bu kuralda yakalanmayabilir.
- **Yanlış pozitif:** Yardımcı ZIP bilinçli konmuş olsa bile GTFS parserlar nested ZIP içeriğini standart feed dosyası olarak işlemez.
