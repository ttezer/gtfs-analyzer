# ARC_011 — Dosya boyutu

> Karar: Kök dizindeki her `.txt` dosyanın byte boyutu bilgi amaçlı raporlanır.
> ⚠️ `.txt` olmayan dosyalar bu envanter ölçümüne girmez.

| Alan | Değer |
|---|---|
| Grup | ARC — Arşiv / Dosya Seviyesi |
| Önem | Bilgi |
| Sınıf | Analytics |
| Aşama | K1 |
| Varlık | File |
| Kimlik alanı | - |
| Skor tabanı | 1 |
| Görünürlük | VA (`R2`, `R3`, `R5`, `R9`) |
| Bloke ettiği kurallar | - |

## Tetikleme koşulu (kesin mantık)
K1 kök dizindeki `.txt` dosyanın sıkıştırmadan açılmış byte uzunluğunu ölçer ve ARC_011 notice'ı üretir. Bilinen veya bilinmeyen `.txt` ayrımı yapılmadan boyut bilgisi kaydedilir.

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** `.txt` olmayan dosyalar bu envanter ölçümüne girmez.
- **Yanlış pozitif:** Bu hata değildir; raporlama/analytics amaçlıdır.

## Mesaj & çözüm önerisi
### R9 Kural Mesajı
- **Kural mesajı:** Dosya boyutu (bilgi)
- **Çözüm önerisi:** Bilgi amaçlıdır; düzeltme gerekmez.

### R2 mesajı/mesajları
- **Ayrıntılı bulgu mesajı:** *"'<file>' boyutu: <n> bayt."*
- **Ayrıntılı çözüm:** *"Bilgi amaçlı; düzeltme gerekmez."*

## Ölçülen alan / değer
- `file`: ilgili `.txt`
- `field`: -
- `line`: dosya seviyesi
- `observed`: `<n> bayt`
