# ARC_003 — İsteğe bağlı dosyada UTF-8 kodlama hatası

> Karar: İsteğe bağlı GTFS dosyası UTF-8 değilse pipeline fatal olmadan devam eder ama kalite uyarısı üretir.
> ⚠️ Zorunlu dosyada bu kuralın yerine ARC_002 fatal davranışı baskındır.

| Alan | Değer |
|---|---|
| Grup | ARC — Arşiv / Dosya Seviyesi |
| Önem | Orta |
| Sınıf | Quality |
| Aşama | K1 |
| Varlık | File |
| Kimlik alanı | - |
| Skor tabanı | 1 |
| Görünürlük | VS (`R2`, `R5`, `R9`) |
| Bloke ettiği kurallar | - |

## Tetikleme koşulu (kesin mantık)
K1 UTF-8 decode hatası yakaladığında dosya zorunlu değilse kayıplı dönüşüm (`String::from_utf8_lossy`) uygular ve ARC_003 üretir.

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** Zorunlu dosyada bu kuralın yerine ARC_002 fatal davranışı baskındır.
- **Yanlış pozitif:** Kayıplı dönüşüm sonrası dosya işlenebilir görünse de karakter kaybı veri kalitesini bozar.
