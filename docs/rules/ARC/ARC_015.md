# ARC_015 — Yinelenen başlık sütunu

> Karar: Aynı CSV başlık adının aynı dosyada birden fazla kez bulunması yapısal hatadır; MobilityData `duplicated_column` (ERROR) birebir karşılığıdır.

## Değişiklik notu (2026-07-24 · Interop terfisi)
MD paritesi doğrulandı: `duplicated_column` (ERROR) — "Duplicated column in CSV. The input file CSV header has the same column name repeated." Birebir aynı olgu; kural Quality/PROJECT_QUALITY'den Interop/MOBILITYDATA_PARITY'ye taşındı, görünürlük Interop konvansiyonuna (VI) hizalandı. Aynı gün FRQ_005 için de parite arandı ve BULUNAMADI (MD `start_and_end_range_out_of_order` yalnız calendar/feed_info/stop_times kapsar, frequencies.txt'i kapsamaz) — FRQ_005 ProjectQuality kalır.

## Tetikleme koşulu (kesin mantık)
K1 trim edilmiş header listesini dolaşır ve daha önce görülen header tekrar gelirse ARC_015 üretir.

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** Semantik olarak aynı ama adı farklı iki sütun bu kurala düşmez.
- **Yanlış pozitif:** Tekrar eden sütunlardan hangisinin doğru değer olduğu belirsizleştiği için kritik kabul edilir.

## Teknik ek
### Dış araç eşleşmesi
- **2026-06-03 doğrulandı:** MobilityData tarafında yakın karşılıklar `csv_parsing_failed`, `duplicated_column`, `empty_column_name`, `empty_file`, `invalid_input_files_in_subfolder`, `invalid_row_length`, `missing_required_file`, `missing_required_field`, `invalid_character` ve UTF-8/IO kaynaklı loader hatalarıdır. Bu projede ARC bazı durumları fatal pipeline davranışıyla birlikte raporlar.
  - https://gtfs-validator.mobilitydata.org/rules.html

### GTFS spec referansı
- **Doğrudan normatif karşılık yok:** GTFS Schedule Reference alan adlarını tanımlar, ancak yinelenen başlık sütununu ayrı ve açık bir Spec ihlali olarak kodlamaz. ARC_015 proje-özel yapısal kalite kuralıdır (2026-07 otorite denetimi).
- 🔗 https://gtfs.org/documentation/schedule/reference/

### Skora katkı
- **severity.weight() = 4.0** (KRİTİK).
- **R1 blocker değil:** Quality sınıfı R1 üretmez (R1 yalnız `GtfsSpec` + Spec + Kritik).
- **R5 genel skor:** Quality sınıf penaltısına girer (ağırlık 0.2).
