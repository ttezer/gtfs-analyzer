# ARC_018 — Boş veri satırı

> Karar: GTFS dosyasında tamamen boş veri satırı bulunmamalıdır.
> ⚠️ Bu kural dosyanın tamamen boş olmasını değil, başlık sonrası tekil veri satırının tüm alanlarının boş olmasını yakalar; dosyada hiç veri satırı yoksa ARC_009 konusudur.

| Alan | Değer |
|---|---|
| Grup | ARC — Arşiv / Dosya Seviyesi |
| Önem | Orta |
| Sınıf | Quality |
| Aşama | K1/K2 |
| Varlık | Row |
| Kimlik alanı | - |
| Skor tabanı | 1 |
| Görünürlük | VS (`R2`, `R5`, `R9`) |
| Bloke ettiği kurallar | - |

## Tetikleme koşulu (kesin mantık)
K1 her veri satırında bütün alanların trim sonrası boş olup olmadığına bakar. Hepsi boşsa ARC_018 üretir ve satırı kayıt listesine eklemez. `stop_times.txt` streaming yolunda aynı kontrol K2 içinde yapılır.

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** Tek bir görünmez ama trim sonrası boş sayılmayan karakter varsa satır tamamen boş kabul edilmeyebilir.
- **Yanlış pozitif:** CSV export sırasında kalan boş satırlar işlevsel veri değildir ve kaldırılmalıdır.
