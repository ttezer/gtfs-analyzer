# ARC_001 — ZIP arşivi açılamadı

> Karar: Validator, GTFS ZIP arşivini `zip::ZipArchive` ile açamıyorsa feed seviyesi fatal hata oluşur.
> ⚠️ ZIP açılıyor ama içindeki dosyalar bozuksa ARC_001 değil ilgili dosya/CSV kuralları devreye girer.

| Alan | Değer |
|---|---|

| Önem | Kritik |
| Sınıf | Spec |
| Aşama | K1 |
| Varlık | Feed |
| Kimlik alanı | - |
| Skor tabanı | 1 |
| Görünürlük | VS_K (`R1`, `R2`, `R5`, `R9`) |
| Bloke ettiği kurallar | - |

## Tetikleme koşulu (kesin mantık)
K1 `zip::ZipArchive::new(cursor)` çağrısını yapar. ZIP yapısı okunamazsa parser `FatalError::ZipUnreadable` döndürür.

Bu kuralda normal notice akışı başlamadan fatal hata dönebilir; bu yüzden kod yazarken hem notice hem fatal hata raporlama yolunu ayrı düşünmek gerekir.

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** ZIP açılıyor ama içindeki dosyalar bozuksa ARC_001 değil ilgili dosya/CSV kuralları devreye girer.
- **Yanlış pozitif:** Dosya GTFS dosyası olsa bile ZIP formatı geçerli değilse validator açısından arşiv okunamazdır.
