# ARC_027 — ZIP girdisinde kullanıcı okuma izni yok

> **Karar:** Bir `.txt` ZIP girdisinin Unix izin bitlerinde kullanıcı-okuma (0400) biti kapalıysa bazı ortamlarda dosya açılamayabilir; bilgilendirme amaçlı işaretlenir. **Düzeltme:** ZIP girdisini user-read (0400) bitiyle yeniden paketleyin.
> ⚠️ Yalnızca ZIP girdisi Unix mode metadata'sı taşıyorsa değerlendirilir; metadata yoksa notice üretilmez.

## Tetikleme koşulu (kesin mantık)
K1 her ZIP girdisini gezerken `zip::ZipFile::unix_mode()` okur:
```
girdi adı .txt ile bitiyor
VE unix_mode() Some(mode)
VE (mode & 0o400) == 0   (kullanıcı-okuma biti kapalı)
→ ARC_027 (dosya başına bir kez)
```
- `unix_mode()` None ise (izin metadata'sı yok, ör. bazı Windows araçları) → sessiz.
- observed_value girdinin oktal izin değeridir (ör. `100`).

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** İzin metadata'sı hiç yazılmamışsa (mode None) gerçek bir erişim sorunu yakalanmaz — kontrol yalnız metadata varsa çalışır.
- **Yanlış pozitif:** Çoğu okuyucu ZIP izin bitlerini yok sayıp içeriği yine okur; bu yüzden Bilgi seviyesindedir, doğrulamayı durdurmaz.
