# ARC_017 — Bilinmeyen sütun

> Karar: Tanınan GTFS dosyasındaki başlık, o dosya için GTFS spesifikasyonunda tanımlı sütunlardan biri olmalıdır.
> ⚠️ `jp_` ile başlayan sütunlar GTFS-JP uzantısı kabul edilip bu kontrolde atlanır; diğer uzantı sütunları ARC_017 olarak raporlanır.

| Alan | Değer |
|---|---|
| Grup | ARC — Arşiv / Dosya Seviyesi |
| Önem | Bilgi |
| Sınıf | Quality |
| Aşama | K1 |
| Varlık | Field |
| Kimlik alanı | - |
| Skor tabanı | 1 |
| Görünürlük | VS (`R2`, `R5`, `R9`) |
| Bloke ettiği kurallar | - |

## Tetikleme koşulu (kesin mantık)
K1 dosya adından beklenen sütun listesini `known_columns(&raw_name)` ile çıkarır. Başlıktaki bir sütun bu listede yoksa ve `jp_` ile başlamıyorsa ARC_017 üretilir.

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** `jp_` prefix'li ama hatalı içerikli sütunlar bu kuralda bilinmeyen sütun sayılmaz.
- **Yanlış pozitif:** Kuruma veya ülkeye özel uzantı sütunları GTFS ana spesifikasyonunda yoksa raporlanır.

## Mesaj & çözüm önerisi
### R9 Kural Mesajı
- **Kural mesajı:** Bilinmeyen sütun (GTFS spesifikasyonunda tanımlı değil)
- **Çözüm önerisi:** GTFS standardı dışındaki sütunları kaldırın veya uzantı kullanımını açıkça yönetin.

### R2 mesajı/mesajları
- **Ayrıntılı bulgu mesajı:** *"'<file>' dosyasında '<header>' GTFS spesifikasyonunda tanımlı değil."*
- **Ayrıntılı çözüm:** *"GTFS standardı dışındaki sütunları kaldırın."*

## Ölçülen alan / değer
- `file`: ilgili `.txt`
- `field`: bilinmeyen başlık adı
- `line`: `1`
- `observed`: GTFS dosya şemasında olmayan sütun
