# ARC_019 — Başlıkta boş sütun adı

> Karar: CSV başlık satırında boş sütun adı bulunmamalıdır.
> ⚠️ Bu kural dosya başına ilk boş başlık adını raporlayıp durur; birden fazla boş başlık varsa tek notice görmeniz normaldir.

| Alan | Değer |

| Görünürlük | VS (`R2`, `R5`, `R9`) |
| Bloke ettiği kurallar | - |

## Tetikleme koşulu (kesin mantık)
K1 ham başlıkları trim ettikten sonra başlık listesini gezer. Trim sonrası boş sütun adı bulunursa ARC_019 üretir ve dosya için bu kontrolü sonlandırır.

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** Aynı dosyadaki ikinci/üçüncü boş başlık ayrıca raporlanmaz.
- **Yanlış pozitif:** Fazladan virgül nedeniyle oluşan boş header parse açısından gerçek yapısal sorundur.
