# STM_041 — stop_id ile location_id/group_id aynı anda kullanılamaz

> Karar: Bir stop_times satırı ya standart `stop_id` kullanır ya da Flex `location_id/location_group_id`; ikisi aynı anda kullanılamaz.
> ⚠️ Feed'de Flex sütunları yoksa kontrol atlanır.

| Alan | Değer |
|---|---|
| Grup | STM — Stop Times |
| Önem | Yüksek |
| Sınıf | Spec |
| Aşama | K2 |
| Varlık | Entity |
| Kimlik alanı | `trip_id` |
| Skor tabanı | 1 |
| Görünürlük | VS (`R2`, `R5`, `R9`) |
| Bloke ettiği kurallar | - |

## Tetikleme koşulu (kesin mantık)
K2 Flex sütunları varsa standart `stop_id` ve Flex lokasyon alanlarını aynı satırda kontrol eder.

`stop_id` dolu ve `location_id` veya `location_group_id` alanlarından biri de doluysa STM_041 üretilir.

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** Feed'de Flex sütunları yoksa kontrol atlanır.
- **Yanlış pozitif:** Standart durak ile Flex bölge aynı satırda farklı servis modelidir; tek satırda çakışır.

## Karışan komşular (ayrım)
| Kural | Ne yakalar | Eksen | Önem · Sınıf · Aşama |
|---|---|---|---|
| **STM_041** | standart stop ve Flex lokasyon çakışıyor | lokasyon modeli | YÜKSEK · Spec · K2 |
| **STM_006** | standart `stop_id` boş | zorunlu stop alanı | KRİTİK · Spec · K2 |
| **STM_039** | Flex lokasyon var ama pencere eksik | Flex pencere | KRİTİK · Spec · K2 |

## Mesaj & çözüm önerisi
### R9 Kural Mesajı
- **Kural mesajı:** stop_id ile location_id/group_id aynı anda kullanılamaz
- **Çözüm önerisi:** Standart durak için yalnız `stop_id`, Flex durak için yalnız `location_id` veya `location_group_id` kullanın.

### R2 mesajı/mesajları
- **Ayrıntılı bulgu mesajı:** *"trip_id '<trip_id>' stop_id ve location_id/group_id aynı anda tanımlı olamaz."*
- **Ayrıntılı çözüm:** *"Standart stop için yalnızca stop_id, Flex stop için yalnızca location_id veya location_group_id kullanın."*

## Ölçülen alan / değer
- `file`: `stop_times.txt`
- `field`: `location_id`
- `line`: satır numarası
- `observed`: lokasyon alanı dolu
- `expected`: boş

## Kod değiştirirken minimum test matrisi
| Senaryo | Beklenen |
|---|---|
| yalnız stop_id | `STM_041` yok |
| yalnız location_id/group_id | `STM_041` yok |
| stop_id + location_id/group_id | `STM_041` |
