# STM_032 — Aynı seferde yinelenen stop_sequence değeri

> Karar: Aynı `trip_id` içinde aynı `stop_sequence` değeri birden fazla kez kullanılmamalıdır.
> ⚠️ Geçersiz sequence değerleri bu kurala gelmeden STM_005 olur.

| Alan | Değer |
|---|---|
| Grup | STM — Stop Times |
| Önem | Düşük |
| Sınıf | Quality |
| Aşama | K2 |
| Varlık | Row |
| Kimlik alanı | `trip_id` |
| Skor tabanı | 1 |
| Görünürlük | VS (`R2`, `R5`, `R9`) |
| Bloke ettiği kurallar | - |

## Tetikleme koşulu (kesin mantık)
K2 her trip için görülen `stop_sequence` değerlerini set içinde tutar.

Aynı `(trip_id, stop_sequence)` çifti ikinci kez görülürse STM_032 üretilir. Sequence parse edilemezse önce STM_005 devreye girer.

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** Geçersiz sequence değerleri bu kurala gelmeden STM_005 olur.
- **Yanlış pozitif:** Aynı durakta bekleme modellemek için aynı sequence tekrar edilmemelidir; farklı sequence kullanılmalıdır.

## Mesaj & çözüm önerisi
### R9 Kural Mesajı
- **Kural mesajı:** Aynı seferde yinelenen stop_sequence değeri
- **Çözüm önerisi:** Her trip içinde `stop_sequence` değerlerini benzersiz yapın.

### R2 mesajı/mesajları
- **Ayrıntılı bulgu mesajı:** *"trip_id '<trip_id>' için stop_sequence <seq> tekrar ediyor."*
- **Ayrıntılı çözüm:** *"Her (trip_id, stop_sequence) çifti stop_times.txt'te benzersiz olmalıdır."*

## Ölçülen alan / değer
- `file`: `stop_times.txt`
- `field`: `stop_sequence`
- `line`: tekrar eden satır
- `observed`: tekrar eden sequence
