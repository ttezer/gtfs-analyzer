# STM_039 — Flex bağlamında pickup/drop_off penceresi eksik

> Karar: Flex lokasyon alanı kullanılan stop_times satırında hem başlangıç hem bitiş penceresi verilmelidir.
> ⚠️ Feed'de Flex sütunları yoksa kontrol atlanır.

| Alan | Değer |
|---|---|
| Grup | STM — Stop Times |
| Önem | Kritik |
| Sınıf | Spec |
| Aşama | K2 |
| Varlık | Entity |
| Kimlik alanı | `trip_id` |
| Skor tabanı | 1 |
| Görünürlük | VS_K (`R1`, `R2`, `R5`, `R9`) |
| Bloke ettiği kurallar | - |

## Tetikleme koşulu (kesin mantık)
K2 Flex sütunları varsa `location_id` veya `location_group_id` varlığını kontrol eder.

Bu lokasyon alanlarından biri doluysa ve `start_pickup_drop_off_window` veya `end_pickup_drop_off_window` alanlarından biri eksikse STM_039 üretilir.

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** Feed'de Flex sütunları yoksa kontrol atlanır.
- **Yanlış pozitif:** Flex lokasyon servisinde zaman penceresi olmadan rezervasyon/pickup davranışı belirsiz kalır.

## Karışan komşular (ayrım)
| Kural | Ne yakalar | Eksen | Önem · Sınıf · Aşama |
|---|---|---|---|
| **STM_039** | Flex lokasyon var ama pencere eksik | zorunlu Flex zaman | KRİTİK · Spec · K2 |
| **STM_040** | pencere var ama booking_rule_id yok | rezervasyon bağı | KRİTİK · Spec · K2 |
| **STM_041** | `stop_id` ile Flex lokasyon aynı anda dolu | lokasyon çakışması | YÜKSEK · Spec · K2 |

## Mesaj & çözüm önerisi
### R9 Kural Mesajı
- **Kural mesajı:** Flex bağlamında pickup/drop_off penceresi eksik
- **Çözüm önerisi:** Flex stop_times satırlarında hem `start_pickup_drop_off_window` hem `end_pickup_drop_off_window` alanını doldurun.

### R2 mesajı/mesajları
- **Ayrıntılı bulgu mesajı:** *"trip_id '<trip_id>' location_id/group_id tanımlı ama <eksik_alan> eksik."*
- **Ayrıntılı çözüm:** *"Flex stop_times için hem start_pickup_drop_off_window hem end_pickup_drop_off_window girin."*

## Ölçülen alan / değer
- `file`: `stop_times.txt`
- `field`: eksik pencere alanı
- `line`: satır numarası
- `expected`: `HH:MM:SS`

## Kod değiştirirken minimum test matrisi
| Senaryo | Beklenen |
|---|---|
| location alanı yok | `STM_039` yok |
| location var, iki pencere dolu | `STM_039` yok |
| location var, pencerenin biri eksik | `STM_039` |
