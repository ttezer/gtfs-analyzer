# STM_042 — stop_headsign Google Transit tarafından desteklenmeyen karakter içeriyor

> Karar: `stop_headsign` değeri Google Transit tarafından desteklenmeyen bazı özel karakterleri içermemelidir.
> ⚠️ Liste dışındaki sorunlu karakterler bu kural tarafından yakalanmaz.

| Alan | Değer |
|---|---|
| Grup | STM — Stop Times |
| Önem | Düşük |
| Sınıf | Interop |
| Otorite kaynağı | GOOGLE_TRANSIT_INTEROP |
| Aşama | K2 |
| Varlık | Row |
| Kimlik alanı | `trip_id` |
| Skor tabanı | 1 |
| Görünürlük | VI (`R2`, `R5`, `R8`, `R9`) |
| Bloke ettiği kurallar | - |

## Tetikleme koşulu (kesin mantık)
K2 `stop_headsign` doluysa karakterleri tarar.

`!`, `$`, `%`, `\`, `*`, `=`, `_` karakterlerinden biri bulunursa STM_042 üretilir. Boş `stop_headsign` hata değildir.

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** Liste dışındaki sorunlu karakterler bu kural tarafından yakalanmaz.
- **Yanlış pozitif:** Bazı yerel gösterimlerde bu karakterler kullanılmak istenebilir; interop açısından kaldırılması önerilir.
