# STM_038 — start_pickup_drop_off_window > end_pickup_drop_off_window

> Karar: Flex pickup/drop-off penceresinde başlangıç zamanı bitiş zamanından sonra olamaz.
> ⚠️ Pencere zamanlarından biri parse edilemezse bu kural çalışmaz.

| Alan | Değer |
|---|---|
| Grup | STM — Stop Times |
| Önem | Yüksek |
| Sınıf | Spec |
| Aşama | K2 |
| Varlık | Entity |
| Kimlik alanı | `trip_id` |
| Skor tabanı | 1 |
| Görünürlük | VS (`R2`, `R5`, `R9`) |
| Bloke ettiği kurallar | - |

## Tetikleme koşulu (kesin mantık)
K2 Flex sütunları varsa `start_pickup_drop_off_window` ve `end_pickup_drop_off_window` değerlerini GTFS saat olarak parse eder.

İki değer de parse edilebildiyse saniyeye çevrilir. Başlangıç saniyesi bitiş saniyesinden büyükse STM_038 üretilir.

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** Pencere zamanlarından biri parse edilemezse bu kural çalışmaz.
- **Yanlış pozitif:** Gece aşımı için GTFS saatleri 24+ biçimde yazılmalıdır; yanlış gün sıfırlama pencereyi ters gösterebilir.

## Karışan komşular (ayrım)

| **STM_039** | lokasyon var ama pencerenin biri eksik | pencere eksikliği | KRİTİK · Spec · K2 |

## Mesaj & çözüm önerisi
### R9 Kural Mesajı
- **Kural mesajı:** start_pickup_drop_off_window > end_pickup_drop_off_window
- **Çözüm önerisi:** Başlangıç penceresini bitiş penceresinden küçük veya eşit yapın.

### R2 mesajı/mesajları
- **Ayrıntılı bulgu mesajı:** *"trip_id '<trip_id>' start_pickup_drop_off_window, end_pickup_drop_off_window'dan sonra."*
- **Ayrıntılı çözüm:** *"start_pickup_drop_off_window değerini end_pickup_drop_off_window'dan küçük ya da eşit yapın."*

## Ölçülen alan / değer
- `file`: `stop_times.txt`
- `field`: `start_pickup_drop_off_window`
- `line`: satır numarası
- `observed`: `<start> > <end>`

## Kod değiştirirken minimum test matrisi
| Senaryo | Beklenen |
|---|---|
| start <= end | `STM_038` yok |
| start > end | `STM_038` |
| start veya end parse edilemez | `STM_038` yok |
