# STM_014 — Segmentte aşırı hız

> Karar: Ardışık duraklar arasındaki hız, yapılandırılmış operasyonel hız eşiğini aşıyorsa analitik hız anomalisi üretilir.
> ⚠️ Koordinat veya zaman eksik segmentler analiz dışı kalır.

| Alan | Değer |
|---|---|
| Grup | STM — Stop Times |
| Önem | Yüksek |
| Sınıf | Analytics |
| Aşama | K6 |
| Varlık | Row |
| Kimlik alanı | `trip_id` |
| Skor tabanı | 3 |
| Görünürlük | VA (`R2`, `R3`, `R5`, `R9`) |
| Bloke ettiği kurallar | - |

## Tetikleme koşulu (kesin mantık)
K6 ardışık stop_times segmentleri için zaman farkı ve mesafe hesaplar.

Hız `config` içindeki rota türüne göre belirlenen eşikten büyükse STM_014 üretilir. Mutlak fiziksel üst sınır olan `700 km/h` aşılırsa önce STM_012 üretilir ve STM_014 o segment için devam etmez.

Mesafe için shape projeksiyonu kullanılabilir; projeksiyon kuş uçuşunun 4 katından büyükse güvenilmez kabul edilip Haversine mesafesine düşülür.

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** Koordinat veya zaman eksik segmentler analiz dışı kalır.
- **Yanlış pozitif:** Çok düşük config eşiği veya hatalı shape projeksiyonu yanlış hız uyarısı üretebilir; kodda shape fallback bu yüzden önemlidir.

## Karışan komşular (ayrım)
| Kural | Ne yakalar | Eksen | Önem · Sınıf · Aşama |
|---|---|---|---|
| **STM_012** | `> 700 km/h` fiziksel imkansız hız | mutlak hız | YÜKSEK · Interop · K6 |
| **STM_014** | config eşiğini aşan hız | analitik hız | YÜKSEK · Analytics · K6 |
| **OPR_008** | aynı trip içinde birden fazla bozuk hız segmenti özeti | operasyon özeti | Analytics · K6 |

## Mesaj & çözüm önerisi
### R9 Kural Mesajı
- **Kural mesajı:** Segmentte aşırı hız
- **Çözüm önerisi:** Segmentteki zaman damgalarını, durak koordinatlarını ve varsa shape eşleşmesini doğrulayın.

### R2 mesajı/mesajları
- **Ayrıntılı bulgu mesajı:** *"'<route_label>' kodlu hattın <yön> yönünde <servis> çalışma takviminde '<trip_id>' seferindeki durak sırası <a>-<b> arası hız <hız> km/h — eşik <eşik> km/h."*
- **Ayrıntılı çözüm:** *"Zaman damgalarını veya durak koordinatlarını doğrulayın; ardışık stop_times arasındaki hız eşiği aşıyor."*

## Ölçülen alan / değer
- `file`: `stop_times.txt`
- `field`: `arrival_time`
- `line`: sonraki durak satırı
- `observed`: hesaplanan hız ve durak çifti
- `expected`: config hız eşiği

## Kod değiştirirken minimum test matrisi
| Senaryo | Beklenen |
|---|---|
| hız config eşiğini aşmıyor | `STM_014` yok |
| hız config eşiğini aşıyor ama `<= 700 km/h` | `STM_014` |
| hız `> 700 km/h` | `STM_012`; aynı segmentte STM_014 yok |
| aynı tripte birden fazla bozuk segment | segment STM_014'leri + `OPR_008` özeti |
