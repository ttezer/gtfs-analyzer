# STM_048 — Gece yarısı sonrası saatler 00:xx yazılmış (24:xx önerilir, duraklar arası)

> Karar: Feed gece yarısını aşan saatleri `24:00:00+` yerine `00:xx` olarak yazmışsa (duraklar arası geriye gidiş olarak görünür) bilgi notu verilir. Analiz için saatler otomatik `24:xx`'e normalize edilir. BİLGİ, Quality.

| Alan | Değer |

| Önem | Bilgi |
| Sınıf | Quality |
| Aşama | K6 |
| Varlık | Feed |

| Skor tabanı | 1 |
| Görünürlük | VS (`R2`, `R5`, `R9`) |
| Bloke ettiği kurallar | - |

## Tetikleme koşulu (kesin mantık)
`normalize_service_day` (K2 sonrası) bir trip'in duraklar arası saatlerini `00:xx → 24:xx` kaydırdıysa o trip "gece yarısını aşan" sayılır (`midnight_wrapped_trips`). Feed'de en az 1 böyle trip varsa STM_048 (feed seviyesi bilgi) üretilir. `config.service_day_start_hour = 0` ise normalizasyon ve bu not kapalıdır.

Bu STM_008'in (gerçek geriye-gidiş) tamamlayıcısıdır: STM_008 elenen gece-yarısı vakalarının toplamı burada bilgi olarak raporlanır.

## Yanlış pozitif / negatif (asıl tasarım riski)
- Bilgi notu; yanlış-pozitif etkisi yok. `00:xx` gerçekten kasıtlıysa (gece yarısı tam) sayım hafif şişebilir.
