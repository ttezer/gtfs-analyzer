# STM_026 — Durak arası mesafe aşırı uzun

> Karar: Ardışık iki durak arasındaki kuş uçuşu mesafe çok büyükse stop_times sırası veya durak koordinatları şüphelidir.
> ⚠️ Koordinat eksikse segment atlanır.

| Alan | Değer |
|---|---|
| Grup | STM — Stop Times |
| Önem | Yüksek |
| Sınıf | Quality |
| Aşama | K6 |
| Varlık | Row |
| Kimlik alanı | `trip_id` |
| Skor tabanı | 2 |
| Görünürlük | VS (`R2`, `R5`, `R9`) |
| Bloke ettiği kurallar | - |

## Tetikleme koşulu (kesin mantık)
K6 ardışık segmentler için Haversine mesafesini hesaplar.

Route type ray ise eşik `config.rail_stop_distance_km`, diğerleri için `50 km`dir. Haversine mesafe eşiği aşarsa STM_026 üretilir.

Bu kural shape projeksiyonu değil, kuş uçuşu mesafe ile karar verir; shape arc projeksiyon hatalarını yanlış pozitif yapmamak için bu tercih bilinçlidir.

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** Koordinat eksikse segment atlanır.
- **Yanlış pozitif:** Uzun mesafe ray/otobüs segmentleri gerçek olabilir; route type ve config eşiği bu yüzden önemlidir.

## Mesaj & çözüm önerisi
### R9 Kural Mesajı
- **Kural mesajı:** Durak arası mesafe aşırı uzun
- **Çözüm önerisi:** Ardışık durakların koordinatlarını ve `stop_sequence` sırasını doğrulayın.

### R2 mesajı/mesajları
- **Ayrıntılı bulgu mesajı:** *"trip_id '<trip_id>' stop_sequence <a>-<b> arası mesafe <mesafe> km."*
- **Ayrıntılı çözüm:** *"stops.txt koordinatlarını ve stop_times.txt sırasını doğrulayın."*

## Ölçülen alan / değer
- `file`: `stop_times.txt`
- `field`: `stop_id`
- `line`: sonraki durak satırı
- `observed`: hesaplanan mesafe
- `expected`: route tipine göre eşik
- `details`: `stop_a`, `stop_b`

## Kod değiştirirken minimum test matrisi
