# STM_006 — stop_id eksik (stop_times)

> Karar: Standart `stop_times.txt` satırında `stop_id` dolu olmalıdır.
> ⚠️ Bu kural yalnızca `stop_times.txt` satırındaki boş `stop_id` değerini yakalar; tanımlı olmayan dolu `stop_id` STM_002 konusudur.

| Kimlik alanı | `trip_id` |
| Skor tabanı | 2 |
| Görünürlük | VS_K (`R1`, `R2`, `R5`, `R9`) |
| Bloke ettiği kurallar | `STM_007`, `STM_008`, `STM_012`, `STM_013`, `STM_014`, `STM_028`, `STM_029`, `OPR_008` |

## Tetikleme koşulu (kesin mantık)
K2 `stop_id` değerini okur. Değer boşsa STM_006 üretilir.

Flex bağlamında `location_id`/`location_group_id` kullanımı ayrıca STM_039-STM_041 kurallarıyla kontrol edilir; bu kart standart `stop_id` zorunluluğunun K2 satır kontrolünü açıklar.

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** Yok; boş değer doğrudan yakalanır.
- **Yanlış pozitif:** Flex satırlarında `stop_id` yerine lokasyon alanları kullanılabilir; bu durumda kartı STM_039-041 ile birlikte okumak gerekir.
