# STM_022 — timepoint geçersiz

> Karar: `timepoint` verilmişse yalnız `0` veya `1` olabilir.
> ⚠️ `timepoint=abc` gibi parse edilemeyen değerler mevcut kodda STM_022 üretmeyebilir.

| Alan | Değer |
|---|---|
| Grup | STM — Stop Times |
| Önem | Orta |
| Sınıf | Spec |
| Aşama | K2 |
| Varlık | Row |
| Kimlik alanı | `trip_id` |
| Skor tabanı | 1 |
| Görünürlük | VS (`R2`, `R5`, `R9`) |
| Bloke ettiği kurallar | - |

## Tetikleme koşulu (kesin mantık)
K2 `timepoint` değerini `parse_u32_raw` ile okur.

Alan boşsa kural çalışmaz. Alan dolu ve parse edilen değer `1`den büyükse STM_022 üretilir. Parse hatası mevcut kodda notice üretmeden `None` olur; bu önemli bir bakım nüansıdır.

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** `timepoint=abc` gibi parse edilemeyen değerler mevcut kodda STM_022 üretmeyebilir.
- **Yanlış pozitif:** `2` gibi sayısal değerler GTFS enum değildir.
