# STM_037 — Flex penceresinde arrival_time/departure_time yasak

> Karar: Flex pickup/drop-off penceresi kullanılan satırda klasik arrival/departure zamanları birlikte kullanılmamalıdır.
> ⚠️ Feed'de Flex sütunları hiç yoksa bu kontroller komple atlanır.

| Alan | Değer |
|---|---|
| Grup | STM — Stop Times |
| Önem | Yüksek |
| Sınıf | Spec |
| Aşama | K2 |
| Varlık | Entity |
| Kimlik alanı | `trip_id` |
| Skor tabanı | 1 |
| Görünürlük | VS (`R2`, `R5`, `R9`) |
| Bloke ettiği kurallar | - |

## Tetikleme koşulu (kesin mantık)
K2 yalnız feed'de Flex sütunlarından biri varsa Flex blok kontrollerini çalıştırır.

`start_pickup_drop_off_window` veya `end_pickup_drop_off_window` doluysa ve aynı satırda `arrival_time` veya `departure_time` parse edilmişse STM_037 üretilir.

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** Feed'de Flex sütunları hiç yoksa bu kontroller komple atlanır.
- **Yanlış pozitif:** Zaman penceresi ile sabit zaman aynı satırda farklı anlamlar taşır; Flex modelde ayrıştırılmalıdır.

## Karışan komşular (ayrım)

## Mesaj & çözüm önerisi
### R9 Kural Mesajı
- **Kural mesajı:** Flex penceresinde arrival_time/departure_time yasak
- **Çözüm önerisi:** Flex penceresi kullanılan satırlarda `arrival_time` ve `departure_time` alanlarını boş bırakın.

### R2 mesajı/mesajları
- **Ayrıntılı bulgu mesajı:** *"trip_id '<trip_id>' Flex penceresi tanımlı iken arrival_time/departure_time yasaktır."*
- **Ayrıntılı çözüm:** *"Flex stop_times satırlarında arrival_time ve departure_time alanlarını kaldırın."*

## Ölçülen alan / değer
- `file`: `stop_times.txt`
- `field`: `arrival_time`
- `line`: satır numarası
- `observed`: arrival/departure değeri
- `expected`: boş

## Kod değiştirirken minimum test matrisi
| Senaryo | Beklenen |
|---|---|
| Flex pencere yok | `STM_037` yok |
| Flex pencere var, arrival/departure boş | `STM_037` yok |
| Flex pencere var, arrival veya departure dolu | `STM_037` |
