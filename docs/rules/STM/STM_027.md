# STM_027 — shape_dist_traveled monoton artmıyor

> Karar: Aynı seferde `shape_dist_traveled` değerleri stop_sequence ilerledikçe azalmamalıdır.
> ⚠️ Eksik mesafe değerleri monotonluk kontrolünde atlanır; kapsam eksikliği STM_017 konusudur.

| Alan | Değer |
|---|---|
| Grup | STM — Stop Times |
| Önem | Yüksek |
| Sınıf | Interop |
| Aşama | K6 |
| Varlık | Row |
| Kimlik alanı | `trip_id` |
| Skor tabanı | 3 |
| Görünürlük | VI_K (`R1`, `R2`, `R5`, `R8`, `R9`) |
| Bloke ettiği kurallar | - |

## Tetikleme koşulu (kesin mantık)
K6 her trip için dolu `shape_dist_traveled` değerlerini sırayla gezer.

Yeni değer önceki değerden `1e-6` toleransından fazla düşükse STM_027 üretilir ve o trip için kontrol kesilir. Boş mesafe alanları atlanır.

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** Eksik mesafe değerleri monotonluk kontrolünde atlanır; kapsam eksikliği STM_017 konusudur.
- **Yanlış pozitif:** Döngü/geri dönüş yapan shape'lerde bile traveled distance kümülatif olmalı, fiziksel geri dönüş değeri azaltmamalıdır.
