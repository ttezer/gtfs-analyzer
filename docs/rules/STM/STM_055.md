# STM_055 — Flex penceresi tanımlıyken continuous_drop_off 1/boş dışında yasak

> Karar: Bir stop_times satırında `start_pickup_drop_off_window` veya `end_pickup_drop_off_window` tanımlıyken `continuous_drop_off` yalnızca `1` (veya boş) olabilir; `0`, `2`, `3` yasaktır — sürekli (hat boyunca istenen yerde) iniş ile talep-üzerine pencere aynı anda modellenemez. GTFS spec [Kesin]. YÜKSEK, Spec.

## Tetikleme koşulu (kesin mantık)
K2 stop_times satırında `has_any_window` (start veya end pickup/drop-off penceresi dolu) iken `continuous_drop_off ∈ {0, 2, 3}` ise STM_055 üretilir. GTFS reference (`stop_times.continuous_drop_off`): "Any value other than `1` or empty is **Forbidden** if `start_pickup_drop_off_window` or `end_pickup_drop_off_window` are defined."

**Kapsam SATIR düzeyindedir** — koşul aynı `stop_time` satırındaki pencere alanlarına bakar. Rota kapsamlı (`routes.txt`) yasak ayrı bir kuraldır (RTS_028, K4).

## Yanlış pozitif / negatif (asıl tasarım riski)
- Boş `continuous_drop_off` örtük olarak "sürekli iniş yok" (1) demektir → susulur, emit yok.
- Enum dışı değerler (`>3`) STM_019'un işidir; STM_055 yalnız `{0, 2, 3}` için tetiklenir → tek hata iki notice üretmez.
- **Simetri notu:** STM_051/052'deki asimetri (pickup_type 0 VE 3 yasak, drop_off_type yalnız 0) buraya TAŞINMAZ — `continuous_*` alanlarında spec her iki alan için de aynı kümeyi ({0,2,3}) yasaklar. Bir sonraki denetimci bunu "asimetrik olmalı" diye düzeltmesin.

## Teknik ek
### Skora katkı
`Yüksek`, taban 1: teorik skor katkısı `1 * 3.0 = 3.0`.

### Hangi raporlarda görünür
`VS`: `R2`, `R5`, `R9`.

### Bağımlılık (bunu maskeleyen root cause'lar)
- Flex pencere alanları (`start`/`end_pickup_drop_off_window`) satırda tanımlı değilse kural tetiklenmez.
- `stop_times.txt` hiç Flex sütunu içermiyorsa satır başı Flex işi tümüyle atlanır (B1 gate).

### Dış araç eşleşmesi
- MobilityData karşılığı **yok**: MD yalnız rota kapsamlı `forbidden_continuous_pickup_drop_off` notice'ını üretir (bizde RTS_028). stop_times tarafı saf spec kontrolüdür → Sınıf `Spec`.

- GTFS Schedule Reference — [stop_times.txt](https://gtfs.org/documentation/schedule/reference/#stop_timestxt), `continuous_drop_off` alanı: "Conditionally Forbidden … if `start_pickup_drop_off_window` or `end_pickup_drop_off_window` are defined."
