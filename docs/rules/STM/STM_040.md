# STM_040 — Flex stop_times'ta pickup/drop_off_booking_rule_id eksik

> Karar: Flex pickup/drop-off penceresi kullanılan satırda en az bir booking rule referansı verilmelidir.
> ⚠️ Feed'de Flex sütunları yoksa kontrol atlanır.

| Alan | Değer |
|---|---|
| Grup | STM — Stop Times |
| Önem | Kritik |
| Sınıf | Spec |
| Aşama | K2 |
| Varlık | Entity |
| Kimlik alanı | `trip_id` |
| Skor tabanı | 1 |
| Görünürlük | VS_K (`R1`, `R2`, `R5`, `R9`) |
| Bloke ettiği kurallar | - |

## Tetikleme koşulu (kesin mantık)
K2 Flex sütunları varsa pickup/drop-off penceresi varlığını kontrol eder.

Herhangi bir pencere alanı doluysa ve hem `pickup_booking_rule_id` hem `drop_off_booking_rule_id` boşsa STM_040 üretilir.

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** Feed'de Flex sütunları yoksa kontrol atlanır.
- **Yanlış pozitif:** Pencere var ama rezervasyon kuralı yoksa kullanıcı davranışı belirsizdir; en az bir rule beklenir.

### R9 Kural Mesajı
- **Kural mesajı:** Flex stop_times'ta pickup/drop_off_booking_rule_id eksik
- **Çözüm önerisi:** Flex penceresi kullanılan satırda `pickup_booking_rule_id` veya `drop_off_booking_rule_id` alanlarından en az birini doldurun.
