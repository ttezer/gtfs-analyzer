# STM_043 — Sefer aşırı fazla durağa sahip (>200)

> Karar: Bir trip'in 200'den fazla durağa sahip olması olası veri birleştirme veya modelleme hatasıdır.
> ⚠️ Trips tablosunda tanımlı olmayan tripler bu kontrolde raporlanmaz; önce STM_001 çözülmelidir.

| Alan | Değer |
|---|---|
| Grup | STM — Stop Times |
| Önem | Bilgi |
| Sınıf | Analytics |
| Aşama | K6 |
| Varlık | Entity |
| Kimlik alanı | `trip_id` |
| Skor tabanı | 1 |
| Görünürlük | VA (`R2`, `R3`, `R5`, `R9`) |
| Bloke ettiği kurallar | - |

## Tetikleme koşulu (kesin mantık)
K6 stop_times index üzerinden her trip'in durak sayısını sayar.

Durak sayısı `> 200` ve trip `trips.txt` içinde tanımlıysa STM_043 üretilir.

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** Trips tablosunda tanımlı olmayan tripler bu kontrolde raporlanmaz; önce STM_001 çözülmelidir.
- **Yanlış pozitif:** Çok uzun hatlarda 200 üstü durak gerçek olabilir; bilgi/analitik uyarı olarak tutulur.

## Mesaj & çözüm önerisi
### R9 Kural Mesajı
- **Kural mesajı:** Sefer aşırı fazla durağa sahip (>200) — olası veri birleştirme hatası
- **Çözüm önerisi:** Trip'in stop_times dizisini gözden geçirin; gerekiyorsa seferi mantıksal segmentlere ayırın.

### R2 mesajı/mesajları
- **Ayrıntılı bulgu mesajı:** *"'<trip_id>' seferinde <count> durak var — olası veri birleştirme hatası."*
- **Ayrıntılı çözüm:** *"Bu sefer için stop_times.txt'i gözden geçirin; seferler mantıksal segmentlere ayrılabilir."*

## Ölçülen alan / değer
- `file`: `stop_times.txt`
- `observed`: durak sayısı
- `expected`: `<= 200`

## Kod değiştirirken minimum test matrisi
