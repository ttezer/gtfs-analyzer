# STM_049 — Gece yarısı sonrası kalkış 00:xx yazılmış (24:xx önerilir, aynı satır)

> Karar: Bir durakta gece yarısını aşan kalkış `24:00:00+` yerine `00:xx` yazılmışsa (aynı satırda kalkış varıştan önce görünür) bilgi notu verilir. STM_007 bu vakalarda bastırılır. BİLGİ, Quality.

| Alan | Değer |
|---|---|
| Grup | STM — Stop Times |
| Önem | Bilgi |
| Sınıf | Quality |
| Aşama | K6 |
| Varlık | Feed |
| Kimlik alanı | `departure_time` |
| Skor tabanı | 1 |
| Görünürlük | VS (`R2`, `R5`, `R9`) |
| Bloke ettiği kurallar | - |

## Tetikleme koşulu (kesin mantık)
K6 STM_007 kontrolünde, bir durakta `departure_time < arrival_time` VE `departure`'ı +24sa alınca `arrival`'a yakınsa (`dep + 86400 − arr ≤ service_day_start_hour*3600`), bu gece yarısını aşan kalkıştır (`00:xx`, `24:xx` yazılmalıydı) → STM_007 bastırılır ve burada sayılır. Feed'de en az 1 böyle durak varsa STM_049 (feed seviyesi bilgi) üretilir. `config.service_day_start_hour = 0` ise kapalıdır.

Bu STM_007'nin (gerçek satır-içi hata) tamamlayıcısıdır.

## Yanlış pozitif / negatif (asıl tasarım riski)
- Bilgi notu; yanlış-pozitif etkisi yok. Eşik altı `00:xx` kalkışlar gece yarısı kabul edilir.
