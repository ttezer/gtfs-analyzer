# STM_021 — Duraklar arası mesafe sıfır veya negatif

> Karar: Ardışık iki farklı `stop_id` aynı koordinata düşüyorsa segment mesafesi sıfırdır ve durak konumu şüphelidir.
> ⚠️ Koordinat eksikse segment analiz dışı kalır.

| Alan | Değer |
|---|---|
| Grup | STM — Stop Times |
| Önem | Yüksek |
| Sınıf | Quality |
| Aşama | K6 |
| Varlık | Row |
| Kimlik alanı | `trip_id` |
| Skor tabanı | 3 |
| Görünürlük | VS (`R2`, `R5`, `R9`) |
| Bloke ettiği kurallar | - |

## Tetikleme koşulu (kesin mantık)
K6 ardışık stop_times segmentinde mesafeyi hesaplar.

Mesafe pratik olarak sıfırsa iki durak kimliği karşılaştırılır. `stop_id` değerleri farklıysa STM_021 üretilir. Aynı `stop_id` ardışık tekrar ediyorsa STM_035 üretilir.

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** Koordinat eksikse segment analiz dışı kalır.
- **Yanlış pozitif:** Aynı fiziksel platformu iki farklı id ile modellemek istenmiş olabilir; bu durumda koordinatlar ayrıştırılmalı veya model netleştirilmelidir.

## Mesaj & çözüm önerisi
### R9 Kural Mesajı
- **Kural mesajı:** Duraklar arası mesafe sıfır veya negatif
- **Çözüm önerisi:** Ardışık farklı durakların `stops.txt` koordinatlarını doğrulayın.

### R2 mesajı/mesajları
- **Ayrıntılı bulgu mesajı:** *"trip_id '<trip_id>' stop_sequence <a>-<b> arası mesafe 0: '<stop_a>' ve '<stop_b>' farklı duraklar ama aynı koordinatta."*
- **Ayrıntılı çözüm:** *"stops.txt'te durak koordinatlarını doğrulayın; ardışık farklı duraklar aynı konumda olmamalıdır."*

## Ölçülen alan / değer
- `file`: `stop_times.txt`
- `field`: `stop_id`
- `line`: sonraki durak satırı
- `observed`: `<stop_a> → <stop_b>`
- `expected`: `> 0 m`
- `details`: `stop_a`, `stop_b`

## Kod değiştirirken minimum test matrisi

| aynı koordinat, aynı stop_id | `STM_035` |
