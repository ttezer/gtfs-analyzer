# OPR_023 — Takvim override boşluğu: pencere içinde hiçbir servis aktif değil

> **Karar:** Config override penceresinde ne base servis ne override servis aktifse route o gün servissiz kalır. ORTA, analitik uyarı. **Düzeltme:** Override penceresinde en az bir uygun servisi aktif tutun.
> ⚠️ Bu kural `calendar_override_rules` config'ine bağlıdır; config yoksa üretilmez.

## Tetikleme koşulu (kesin mantık)
`k6_analytics::check_calendar_override_analytics()` içinde:
```
for rule in config.calendar_override_rules
VE date ∈ [rule.start_date, rule.end_date]
VE base_service_ids içinde aktif servis yok
VE override_service_ids içinde aktif servis yok
→ OPR_023
```
- Bu `(base_active=false, override_active=false)` durumudur.
- Doğru durum `(false, true)` yani base kaldırılmış, override eklenmiş halidir.
- Details servis setleri ve örnek tarihleri taşır.

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** Config yoksa veya pencere yanlışsa boşluk raporlanmaz.
- **Yanlış pozitif:** O gün bilinçli servis yokluğu planlandıysa config override penceresi fazla geniş olabilir.

## Mesaj & çözüm önerisi
### R9 Kural Mesajı
- **Kural mesajı:** Takvim override boşluğu: pencere içinde hiçbir servis aktif değil
- **Çözüm önerisi:** Override penceresinde base veya override servislerinden en az birini aktif tutun.

### R2 mesajı/mesajları
- **Ayrıntılı bulgu mesajı:** *"'{route_id}' hattında {count} günde ne base ({base_services}) ne override ({override_services}) servisi aktif — hat servissiz kalmış. İlk gün: {first_date}."*
- **Çözüm önerisi:** *"Override penceresinde hem base hem override servisini aktif tutun."*

## Ölçülen alan / değer
- **Dosya/alan:** config `calendar_override_rules`; `calendar.txt` / `calendar_dates.txt`
- **Gözlenen değer:** Base pasif, override pasif.
- **Beklenen değer:** Override penceresinde en az bir servis aktif.

## Kod değiştirirken minimum test matrisi
- Config var, base pasif override pasif → OPR_023 çıkmalı.
- Config var, base pasif override aktif → OPR_023 çıkmamalı.
- Config yok → OPR_023 çıkmamalı.
- OPR_021/022 ile aynı güne karışmamalı.
