# OPR_022 — Takvim override uygulanmamış: override gününde base servis çalışıyor

> **Karar:** Config'e göre override servisinin çalışması beklenen pencerede override aktif değilken base servis aktif kalıyorsa override uygulanmamıştır. YÜKSEK, analitik uyarı. **Düzeltme:** Override servisini ilgili gün için `exception_type=1` ile ekleyin.
> ⚠️ Bu kural config tabanlıdır; `calendar_override_rules` yoksa aynı durum OPR_022 olarak raporlanmaz.

## Tetikleme koşulu (kesin mantık)
`k6_analytics::check_calendar_override_analytics()` içinde:
```
for rule in config.calendar_override_rules
VE date ∈ [rule.start_date, rule.end_date]
VE base_service_ids içinden en az biri aktif
VE override_service_ids içinde aktif servis yok
→ OPR_022
```
- Bu `(base_active=true, override_active=false)` durumudur.
- Base çalışıyor ama beklenen override eklenmemiş kabul edilir.
- Details config servis setlerini taşır.

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** Config'te override penceresi tanımlanmadıysa kural çalışmaz.
- **Yanlış pozitif:** O gün override beklenmiyorsa config penceresi veya servis listesi yanlıştır.

## Mesaj & çözüm önerisi
### R9 Kural Mesajı
- **Kural mesajı:** Takvim override uygulanmamış: override gününde base servis çalışıyor
- **Çözüm önerisi:** Override servisini `calendar_dates.txt` ile ekleyin (`exception_type=1`).

### R2 mesajı/mesajları
- **Ayrıntılı bulgu mesajı:** *"'{route_id}' hattında {count} günde override servisi ({override_services}) bekleniyor ancak aktif değil; base servis ({base_services}) çalışıyor. İlk gün: {first_date}."*
- **Çözüm önerisi:** *"Override günü için override servisini calendar_dates.txt ile ekleyin (exception_type=1)."*

## Ölçülen alan / değer
- **Dosya/alan:** config `calendar_override_rules`; `calendar.txt` / `calendar_dates.txt`
- **Gözlenen değer:** Base aktif, override pasif.
- **Beklenen değer:** Override penceresinde override aktif olmalı.

## Kod değiştirirken minimum test matrisi
- Config var, base aktif override pasif → OPR_022 çıkmalı.
- Config var, base pasif override aktif → OPR_022 çıkmamalı.
- Config yok → OPR_022 çıkmamalı.
- OPR_021 ile birlikte yanlış aynı güne düşmemeli.
