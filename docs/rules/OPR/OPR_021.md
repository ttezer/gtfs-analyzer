# OPR_021 — Takvim override çakışması: override ve base eş zamanlı aktif

> **Karar:** `calendar_override_rules` config penceresinde override servisi aktifken base servisi de aktif kalmışsa takvim override çakışması vardır. YÜKSEK, analitik uyarı. **Düzeltme:** Override gününde base servisi `exception_type=2` ile kaldırın.
> ⚠️ Bu kural yalnızca config içindeki `calendar_override_rules` tanımlıysa çalışır; config boşsa OPR_021 üretilmez.

## Tetikleme koşulu (kesin mantık)
`k6_analytics::check_calendar_override_analytics()` içinde:
```
for rule in config.calendar_override_rules
VE date ∈ [rule.start_date, rule.end_date]
VE base_service_ids içinden en az biri aktif
VE override_service_ids içinden en az biri aktif
→ OPR_021
```
- Doğru override durumu `(base_active=false, override_active=true)` olarak kabul edilir.
- Details base/override servisleri ve örnek tarihleri taşır.
- Config doğrulaması `gtfs-config` katmanında yapılır.

## Yanlış pozitif / negatif (asıl tasarım riski)
- **Yanlış negatif:** Config'te override ilişkisi tanımlı değilse bu kural hiç çalışmaz.
- **Yanlış pozitif:** Base ve override'ın birlikte çalışması bilinçli ise config kuralı yanlış tanımlanmış olabilir.

## Mesaj & çözüm önerisi
### R9 Kural Mesajı
- **Kural mesajı:** Takvim override çakışması: override ve base eş zamanlı aktif
- **Çözüm önerisi:** Override gününde base servisi `calendar_dates.txt` ile kaldırın (`exception_type=2`).

### R2 mesajı/mesajları
- **Ayrıntılı bulgu mesajı:** *"'{route_id}' hattında {count} günde override servisi ({override_services}) aktif ancak base servisi ({base_services}) de aktif kalmış. İlk gün: {first_date}."*
- **Çözüm önerisi:** *"Override gününde base servisi calendar_dates.txt ile kaldırın (exception_type=2)."*

## Ölçülen alan / değer
- **Dosya/alan:** config `calendar_override_rules`; `calendar.txt` / `calendar_dates.txt`
- **Gözlenen değer:** Base ve override aynı gün aktif.
- **Beklenen değer:** Override gününde base pasif, override aktif.

## Kod değiştirirken minimum test matrisi
- Config var, base ve override aktif → OPR_021 çıkmalı.
- Config var, base pasif override aktif → OPR_021 çıkmamalı.
- Config yok → OPR_021 çıkmamalı.
- Details `base_services`, `override_services`, tarih örneklerini taşımalı.
